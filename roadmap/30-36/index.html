30-36ヶ月

B 中程度 数・量・空間認知

3までの理解・形・比較

「3つちょうだい」が正しくできるのは3歳前後から

芽生えるもの: 小さな数の正確な理解（1〜3） / 丸・三角・四角の区別 / 長い/短い・重い/軽いの比較

👨 高レバレッジ活動
  • 「2つちょうだい」の数の実践
  • 仲間分け・形さがし（「まるいもの、どこ？」）

散歩を「形さがし」「数さがし」の探検に変える。標識・タイヤ・窓——街は教材だらけ。

関連生活の中で数える仲間分け（分類あそび）数量感覚は「数えること」より「比べること」から空間認知を育てる
B 中程度 社会情動・共感

友だちへの関心と気持ちの言葉

—

芽生えるもの: 他児と関わろうとする（貸し借りはまだ難しい） / 「かなしい」「おこってる」など感情語 / 簡単な思いやり行動

👨 高レバレッジ活動
  • 絵本の登場人物の気持ちを一緒に考える
  • 貸し借りの練習は大人が仲介して成功体験に

「パパ、いま嬉しいよ」と父自身の感情を言葉で開示する。感情語のモデルは効く。

⚠️ 受診の目安（赤旗）
  • 他者への関心が極端に乏しい
  • やりとりの成立しにくさが続く
関連気持ちの実況（感情のことば化）社会情動・共感かんしゃく・イヤイヤ期の対応感情のラベリング
B 中程度 微細運動・手の巧緻性

描く形・はさみの入り口・着脱

円のまねがきは3歳前後

芽生えるもの: 円・線のまねがき / 子ども用はさみの一回切り / 大きなボタン・靴の着脱への挑戦

👨 高レバレッジ活動
  • お絵かきの時間を日常に
  • 着替えの「自分でできる部分」を任せる

不器用でも急かさない。「自分でできた」の総量が就学前の自信を作る。

関連微細運動・手の巧緻性キッチンお手伝い（混ぜる・ちぎる・運ぶ）スプーン・コップ・はさみ
B 中程度 好奇心・探索・遊び

協同遊びの入り口・ルールのある遊び

—

芽生えるもの: 簡単なルールのある遊び（かくれんぼ・むっくりくまさん） / 役割のあるごっこ / 「一緒に」作る遊び

👨 高レバレッジ活動
  • 家族でルール遊び（だるまさんがころんだ等の簡易版）
  • 積み木やブロックの共同制作

ルールを守る・負けても大丈夫、を遊びの中で。父がわざと負けて「くやしい〜！でも楽しかった」とモデルを見せる。

関連ダンス＆ストップ好奇心・探索・遊びオープンエンドな遊びふり遊びの育ち方
B 中程度 音楽・リズム・聴覚

リズムの正確さと歌の世界

—

芽生えるもの: 拍に合わせる正確さの向上 / レパートリーの拡大 / 「かなしい曲/たのしい曲」の感受

👨 高レバレッジ活動
  • コール＆レスポンス・合奏ごっこ
  • 曲の気分を言葉にする（「この曲どんな気持ち？」）

父のプレイリストを一緒に聴いて感想を言い合う。音楽の好みの世界を広げるのは父の音楽体験。

関連よびかけソング（コール＆レスポンス）音楽・リズム・聴覚うたと言葉
C 限定的 視覚・感覚統合

観察の解像度が上がる

—

芽生えるもの: 細部への気づき（虫の脚・葉の筋） / 季節・天気の変化への言及 / 感覚の記憶（「この前の海とおなじ匂い」）

👨 高レバレッジ活動
  • 虫めがね・観察さんぽ
  • 季節の定点観察（同じ木を見に行く）

「ほんとだ、よく見つけたね」——子の発見に驚ける父が、観察する子を育てる。

関連はっぱ・どんぐり集め外あそびと自然の科学感覚の好き嫌い感触遊び（メッシー・プレイ）— 「汚れる」ことが学びになる
B 中程度 読み聞かせ・リテラシー

物語る側へ — お話づくりと文字の芽

—

芽生えるもの: 自分でお話を作る / 経験を順序立てて話す芽 / 自分の名前の文字への興味

👨 高レバレッジ活動
  • 絵本でお話づくり・寝る前の「今日いちばん」
  • 名前の文字を遊びで見せる（教え込まない）

「それでどうなったの？」と続きを促す聞き手役。物語る力は聞いてくれる人がいて育つ。

⚠️ 受診の目安（赤旗）
  • ことばのやりとり・簡単な会話が成立しにくい状態が続く
関連絵本でお話づくり寝る前の「今日いちばん」対話的読み聞かせの実際絵本の選び方と、続く読書習慣のつくり方
B 中程度 言語・コミュニケーション

会話と質問期

3語以上の文・質問は3歳前後

芽生えるもの: 多語文で話す / 「なぜ？」の質問 / 簡単な物語の理解と再話

👨 高レバレッジ活動
  • 対話的読み聞かせ
  • 絵本でお話づくり

「なぜ」に付き合い、一緒に考える。答えを急がず対話を楽しむ。

⚠️ 受診の目安（赤旗）
  • 3歳で言葉が非常に少ない
  • 会話が成立しない
  • 一度できたことの退行
関連絵本でお話づくり言語・コミュニケーションことばの爆発と二語文
B 中程度 粗大運動・スポーツ

ジャンプ・バランスの向上

両足ジャンプは2〜3歳

芽生えるもの: 両足でジャンプ / 片足立ちの芽 / つま先立ち・その場回転

👨 高レバレッジ活動
  • ダンス＆ストップ
  • 多様な運動遊び（ABC）

競技に絞らず、走る・跳ぶ・登る・投げるを幅広く（早期特化しない）。

⚠️ 受診の目安（赤旗）
  • 歩行・粗大運動の明確な遅れや退行
関連ダンス＆ストップ粗大運動・スポーツ走る・跳ぶ・投げる危ないあそび（リスクのある遊び）— 「適度な危なさ」は学びになる
B 中程度 実行機能・自己制御

ごっこの複雑化と切り替え

—

芽生えるもの: 筋のあるごっこ遊び / ルールの切り替え / 短い指示の記憶と実行

👨 高レバレッジ活動
  • ごっこ遊び（見立て）
  • 仲間分け（基準の切り替え）
  • ダンス＆ストップ

遊びの中で少しだけ難しいルールを足し、足場をかける。

関連ごっこ遊び（見立て）実行機能・自己制御「待てる子」の育て方「集中できる子」の育て方
