# 03 — 執筆規約（Authoring Guide / Style）

読み手は「0歳児を持つ、忙しく、真面目で、少し不安な父親」。その人が**5分で読めて、今日ひとつ試せる**——それが基準。

## 文体

- **敬体（です・ます）**。断定しすぎず、しかし歯切れよく。
- 主語は基本「父（あなた）」と「子（娘）」。専門用語は初出で1行かみ砕く。
- 1文は短く。1段落3〜5文まで。長い羅列は表・リストに逃がす。
- **恐怖で動かさない。** 「〜しないと手遅れ」ではなく「〜すると育ちやすい」。

## 各コンテンツの型（必ず含める）

1. **なぜ重要か**（子の人生にどう効くか、1〜2文）
2. **科学的機序**（`:::science` で"なぜ効くか"を具体的に）
3. **父が今日できること**（`:::father` / `steps`。抽象で終わらせない）
4. **注意・境界**（あれば `:::warning`。安全・やりすぎ・スコープ外）
5. **つながり**（`related` で関連ページへ。孤立させない）

## やってはいけない表現

- 「必ず」「絶対」「〜させれば天才に」等の断定・誇張
- 他児との比較を促す書き方
- 基本育児（授乳・寝かしつけ手技・病気対応）への踏み込み（スコープ外）
- 特定商品・教室名の推奨

## 見出し・長さの目安

- `chapter`: 見出し3〜6個、`reading_minutes` 5〜9分程度
- `summary`: 1〜2文（カード・一覧に出るので単体で意味が通ること）
- `activity`: `steps` は3〜5手、家にあるもので完結を優先

## 図（推奨）

文章だけにしない。関係・順序・比較は**インラインSVG**（`\`\`\`svg` フェンス）で図に。色は `design-system` のトークン相当（緑=成長、青=科学、琥珀=注意）に寄せる。
