## 作業の型（毎回これだけ守る）

1. `git pull --rebase origin main`（または main から取り直す）
2. `content/` に追加（スキーマは `02-content-schema.md`）
3. `node build/build.mjs` で**警告ゼロ・リンク切れゼロ**を確認
4. commit → push → PR → squash マージ → デプロイ成功を確認

**注意**: PRはスカッシュマージされるので、次の作業は必ず main から取り直すこと
（前のブランチに積むと衝突する）。
