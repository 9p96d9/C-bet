# 05 — エビデンス方針（Evidence Policy）

この資料の信頼性の核。**すべての主張に等級を付し、誇張しない。**

## 等級

| 等級 | 意味 | 典型的な根拠 |
|---|---|---|
| **A** | 強い根拠 | メタ分析・複数のRCT・確立した神経科学 |
| **B** | 中程度 | 一貫した観察研究・縦断研究・複数の支持（因果は限定的） |
| **C** | 限定的 | 理論・専門家の合意・小規模/単発研究 |
| **D** | 弱い/要注意 | 逸話・人気だが根拠が薄い・商品化された主張 |

## 付け方のルール

1. **迷ったら1段下げる。** 過小評価は誠実、過大評価は有害。
2. **相関を因果と書かない。** 父親関与・語彙格差などは主に相関 → B止まり。「関連する」と書き、「〜すれば必ず〜になる」とは書かない。
3. **効果量に触れる。** 「統計的に有意」と「実生活で大きい」は別。小さい効果は小さいと書く。
4. **D等級＝禁止ではない。** 「過信するな」の意味。神話・商品化された言説は [神話セクション](/myths/) で `verdict` 付きで是正する。
5. **本物の臨界期（視覚・聴覚・第一言語の音韻）だけは"時間が効く"と明言してよい**（A）。それ以外の「手遅れ」表現は使わない。

## 出典

- 一次情報源は `content/09-appendix/references.mjs` に集約。
- 主要な主張には出典を紐づける（`reference` の `tags` と各コンテンツを対応づけ）。
- 日本語圏の読者向けに、原則は公的機関（AAP、Harvard Center on the Developing Child、WHO、厚労省・自治体資料等）を優先。

## トーン

- 断定より条件付き（「〜と関連する」「〜の傾向がある」）。
- 不確実性を隠さない。「まだよく分かっていない」と書ける勇気を持つ。
- 親を脅さない。恐怖ではなく、できることの提示で動機づける。
