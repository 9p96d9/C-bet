# 01 — 情報アーキテクチャ（Information Architecture）

サイト全体の地図。各セクションは `content/<番号-slug>/` に対応する。
ナビゲーション順序は `content/_manifest.mjs` が単一の情報源（source of truth）。

---

## 1. トップレベル構造（10セクション）

```
0  はじめに (intro)            資料の歩き方・前提・エビデンスの読み方・免責
1  土台の科学 (science)         なぜ0-3歳が効くのか。可塑性・敏感期・愛着・ストレス・睡眠・栄養・運動
2  父親の強み (fathers-edge)    父親関与の科学。母親と差別化できる固有の貢献
3  発達ドメイン (domains)       10ドメインの深掘りハブ（能力の柱ごと）
4  月齢ロードマップ (roadmap)    0-36ヶ月。マイルストーン＋その時期の高レバレッジ活動
5  実践図鑑 (activities)        父親が今日できる活動カード。ドメイン×月齢でフィルタ
6  環境デザイン (environment)   玩具・絵本・スクリーン・家庭の設え・遊び場
7  神話と落とし穴 (myths)       早期教育の過剰主張・"窓は閉じる"神話の是正
8  記録と見守り (track)         発達の記録・急がない姿勢・受診の目安（赤旗）
9  付録 (appendix)             用語集・参考文献・チェックリスト・道具リスト
```

---

## 2. 各セクションの内訳

### 0. はじめに `intro`
- この資料の使い方 / 誰のための資料か
- 大前提：土台7原則（愛着・応答性・睡眠・栄養・運動・言語環境・遊び）
- エビデンスの読み方（A〜D等級の意味）
- やってはいけないこと（過剰・比較・成果主義）
- 免責事項（医療助言ではない）

### 1. 土台の科学 `science`（`chapter`型）
- `01` 3歳までがなぜ特別か：数字で見る脳の発達
- `02` 脳の可塑性：シナプス形成・刈り込み・髄鞘化
- `03` 敏感期 vs 臨界期：**神話の是正**（多くの窓は閉じない）
- `04` 愛着（アタッチメント）：すべての探索の安全基地
- `05` サーブ＆リターン：最強にして無料の介入
- `06` 毒性ストレス vs ポジティブストレス：コルチゾールと発達
- `07` 睡眠と記憶固定：なぜ寝ると賢くなるか
- `08` 栄養と脳（DHA・鉄・タンパク質・腸脳相関の基礎）
- `09` 運動が認知をつくる：身体から脳へ
- `10` 言語シャワーの科学：語りかけ量と語彙格差（"3000万語"の再検討）

### 2. 父親の強み `fathers-edge`（`chapter`型）
- `01` 父親関与のエビデンス概観：何に効くか
- `02` ラフ＆タンブル遊び：情動調整とリスク学習
- `03` 探索を促す「押し出す」愛着スタイル
- `04` 父親の言語入力の質（"ブリッジ仮説"）
- `05` 母親とチームを組む：役割の相補性
- `06` 働く父・不在時間の設計：量より接続の質

### 3. 発達ドメイン `domains`（各ドメインが `domain-hub` ＋複数 `chapter`）
1. 言語・コミュニケーション（`language`）／バイリンガル含む
2. 粗大運動・スポーツ的身体能力（`gross-motor`）／physical literacy・FMS
3. 微細運動・手の巧緻性（`fine-motor`）
4. 数・量・空間認知（`math-spatial`）
5. 実行機能・自己制御（`executive-function`）★学業最強予測因子
6. 音楽・リズム・聴覚（`music`）
7. 視覚・感覚統合（`sensory`）
8. 社会情動・共感（`social-emotional`）
9. 好奇心・探索・遊び（`play`）
10. 読み聞かせ・リテラシー前駆（`literacy`）

### 4. 月齢ロードマップ `roadmap`（`milestone`型データ）
月齢帯 8区分：`0-3` `3-6` `6-9` `9-12` `12-18` `18-24` `24-30` `30-36`（月単位）。
各帯 × 各ドメインで：**その時期に芽生えるもの／高レバレッジ活動／赤旗サイン**。

### 5. 実践図鑑 `activities`（`activity`型カード）
父親が今日できる活動カード。ドメイン・月齢・所要時間・道具でフィルタ。
目標規模：最終的に数百枚（Opusが増築）。

### 6. 環境デザイン `environment`（`chapter`型）
- 玩具の選び方（オープンエンドな遊具の原則）
- 絵本の選び方と蔵書構築
- スクリーンタイム方針（月齢別・エビデンス）
- 家庭の"用意された環境"（モンテッソーリ的発想）
- 屋外・自然・リスクのある遊び場

### 7. 神話と落とし穴 `myths`（`myth`型カード）
- "窓は永遠に閉じる"神話 / フラッシュカードで天才 / 知育DVD
- 早期の読み書き先取り / 完璧な親 / 比較と焦り など

### 8. 記録と見守り `track`（`chapter`＋チェックリスト）
- 発達の記録の付け方（急がせない）
- 個人差の正常範囲
- 受診の目安（赤旗サイン一覧）

### 9. 付録 `appendix`
- 用語集（`glossary`）
- 参考文献（`reference`）
- 月齢別クイックチェックリスト
- 道具・素材リスト

## 3. 横断ナビゲーション（Cross-cutting Access）

同じコンテンツに複数の入口を用意する（"多次元アクセス"）。

- **ドメイン軸**：言語／運動／数量…から入る
- **月齢軸**：ロードマップから「今うちの子は◯ヶ月」で入る
- **時間軸**：「5分でできる」活動フィルタ
- **目的軸**：「勉強に効く」「スポーツに効く」タグ

これを実現するため、`activity` と `milestone` は必ず `domains[]` と `ageRange` を持ち、ビルド時に相互リンクを自動生成する（→ `06-extend-guide-for-opus.md`）。
