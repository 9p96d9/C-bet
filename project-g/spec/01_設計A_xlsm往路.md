# 01 設計 A ― xlsm 往路：CSV を読み、表示期間を指定して xlsx を出す

前提：`00_共通仕様_プロジェクトG工程表変換.md` を先に読むこと。本書は差分のみ書く。

---

## 1. 成果物

| 成果物 | 内容 |
|---|---|
| `プロジェクトG変換ツール.xlsm` | 監督 PC の Excel で動く。CSV 選択 → Start/End 入力 → 「変換実行」 → xlsx を別名保存 |
| 出力 `<CSV名>_<Start>-<End>.xlsx` | 業者用。**マクロなし**。CSV と同じフォルダーに保存。既存なら連番を付けて上書きしない |
| `変換ログ.txt` | 1 回の実行につき 1 本。読み込み件数、除外件数、検査結果 |
| `設計A_実装メモ.md` | 実装時に判明した仕様の解釈・PDF との差異・未対応事項 |

**スコープ外（v1）**：復路、詳細工程列、0.5 日、祝日、複数 CSV の結合。

---

## 2. 動作環境

- Windows、Excel 2016 以降（Microsoft 365 想定）、VBA
- 開発補助に PowerShell を使う場合は **Windows PowerShell 5.1** のみ（PowerShell 7 不可、追加モジュール不可）
- xlsm の配布は ZIP。展開後の Mark of the Web 解除手順を `使い方` シートに書く

---

## 3. xlsm の構成

| シート | 役割 |
|---|---|
| `00_Control` | CSV パス（B3）、Start（B5）、End（E5）、実行ボタン、結果（B9）、版（B14） |
| `T09_Audit` | CSV を 1 行 1 工程で正規化した監査表（工程ID、名前、開始行、終了行、開始日、終了日、形状、矢印、線種、太さ、色、背景色、斜行、中間ノード日付、ノード形状、削除フラグ）。**列見出しで引く** |
| `T10_Layout` | 業者用シートの**生成元**。変換実行で毎回クリアして再生成 |
| `使い方` | 監督向け手順 |

VBA モジュール：

| モジュール | 責務 |
|---|---|
| `CsvReader` | RFC 4180 パース、BOM 除去、見出し名→列 index の辞書化、メタ行の `工程表の期間` 取得 |
| `Model` | 工程レコード型（`Type`）と配列。日付は `Date` 型に正規化（ISO の日付部のみ） |
| `Layout` | 表示期間 → 日付列、行番号 → シート行、月結合ヘッダー、土日判定 |
| `Render` | `T10_Layout` へセルで描く（→ 4 章） |
| `Export` | `T10_Layout` を新規ブックへコピーし `FileFormat:=51` で保存。保護・入力規則・非表示シートを付ける |
| `Verify` | 出力 xlsx を読み戻して検査（→ 6 章） |
| `Main` | `RunConversion`。上記を順に呼ぶ。エラーは B9 とログへ |

**既存資産の流用可否**：v11.1 の `ProjectGCsv`（パーサ・JSON 名取り出し）と `ProjectGVariablePeriod`（期間ヘッダー）は流用してよい。ただし `EXPECTED_ROWS` / `EXPECTED_HEADERS` の停止条件、列幅を B〜CN の 91 列に固定している箇所、`ThisWorkbook.Save`、再オープン監査は**削除**する。`ProjectGVariableShapes` は使わない。

## 4. 描画仕様（セルのみ。Shape 禁止）

### 4.1 格子

共通仕様 4 章のとおり。追加：

- 日付列の幅：3.5（文字単位）程度。行高：既定
- A 列幅：18
- 行 1〜3 を固定（ウィンドウ枠の固定）、A 列も固定
- 土日列：行 2〜最終行の背景を `#EEEEEE`

### 4.2 工程の描き方

全形状を**バー**として描く。行 = `開始日の行番号 + 3`。

| 形状 | セル表現 |
|---|---|
| straight, xElbow, yElbow, crank, gate | 開始境界〜終了境界のセルに**下罫線**（線色、`dash` なら破線、太さは 1→細、2→中、2.5 以上→太）。矢印 `arrow` なら終了列の**次のセル**左端に文字 `▶`（線色、左寄せ）。**終了行が開始行と違う場合**は、終了行の終了境界の**前のセル**に `▼`（線色）を置き「ここに繋がる」ことだけ示す |
| boxS / boxM / boxL | 開始〜終了のセルに**塗り**（背景色があればそれ、なければ線色の 25% 相当の淡色）＋外枠罫線（線色）。S/M/L の差は行高では出さず、`使い方` に「S/M/L は プロジェクトG 上の高さ差、Excel では同一」と明記 |
| barAutoAdjust | 開始〜終了のセルに**塗り**（背景色 or 線色）。枠なし |
| barProcessNameAdjust | 開始〜終了のセルに**塗り**（線色の淡色）。名前は開始セルに |
| 工程線名 | **開始セルの値**に `name` を入れる（左寄せ、折り返しなし、線色で太字）。セル幅を超えても隣が空なら表示される |
| 中間ノード | 描かない（v1） |
| 工程削除に値 | 描かない。ログに件数 |
| 期間外 | 描かない。ログに件数。一部重複はクリップ |

**土日をまたぐバー**：土日列は背景灰のまま、罫線/塗りは連続させる（プロジェクトG の点線は再現しない）。

### 4.3 データ列（復路の入口になる。v1 でも出力する）

`T10_Layout` の**日付列より左**に、業者が直すセルを置く。

| 列 | 内容 | 保護 |
|---|---|---|
| A | 行見出し | ロック |
| B | 工程線名（`name`） | ロック |
| C | **開始日**（`yyyy/mm/dd`） | **編集可** |
| D | **終了日** | **編集可** |
| E | 日数（`=NETWORKDAYS(C,D)`） | ロック |
| F 以降 | 日付列 | ロック |

→ 共通仕様 4 章の「B 列が Start」は、**データ列 4 本を挟むので F 列が Start** に読み替える（`Start` 列 = 6、日付 index `n` → 列 `6 + n`）。共通仕様の表現は「最初の日付列」と読むこと。

1 工程が 1 行に対応しない場合（同じ行に 2 工程が開始する場合）は、**後勝ちではなくエラー**にしてログに出し、v1 では 2 本目を次の空行に落とす。サンプルで発生するか確認して実装メモに書く。

### 4.4 条件付き書式（任意だが推奨）

業者が C/D を直したときにバーが追従するよう、罫線/塗りを**条件付き書式**で付ける：

`=AND(F$2<>"", F$2>=$C5, F$2<=$D5)` → 塗り or 下罫線

行ごとに色が違うため、**行単位**でルールを作る（工程数分）。ルール数が多くなるが、23 件では問題ない。1000 件級では性能を実測して判断。

v1 では「静的塗り」と「条件付き書式」のどちらかを選び、実装メモに理由を書く。**推奨は条件付き書式**（復路の前提である「日付を直せばバーが動く」がそのまま手に入る）。

### 4.5 非表示シート `_data`

`T09_Audit` の全列（**元 CSV の 124 列もそのまま**）を `_data` として出力 xlsx に含め、**非表示**にする。工程ID で `T10_Layout` の行と対応させる（`T10_Layout` の末尾列に工程ID を置いてロック＋非表示列にする）。復路はここを読む。

---

## 5. 出力 xlsx の保護

- `T10_Layout` 相当シート：シート保護（パスワードなし）。C・D 列のみロック解除。行の挿入・削除・並べ替えを禁止
- C・D 列に入力規則：日付、`工程表の期間` 内、`D >= C`
- `_data` 非表示、ブック保護でシートの再表示を抑止（パスワードなしで可）
- ブック名にマクロ痕跡を残さない（`FileFormat:=51`）

---

## 6. 検査（機械）

変換実行の最後に出力 xlsx を読み戻し、以下を全て満たしたときだけ「合格」をログに書く。1 件でも NG なら xlsx を残したまま「不合格」と理由を出す。

| 検査 | 条件 |
|---|---|
| 件数 | `T10_Layout` に描いた工程数 ＋ 期間外除外数 ＋ 削除除外数 ＝ CSV 工程数 |
| 位置 | 各工程について、塗り/罫線の**最初の列の日付 ＝ 開始日**、**最後の列の日付 ＝ 終了日**（セルを読んで判定） |
| 行 | 各工程の行 ＝ `開始日の行番号 + 3` |
| データ列 | C/D の値 ＝ CSV の開始日/終了日 |
| ヘッダー | 日付列数 ＝ `End − Start + 1`、行 2 の値が連続日付 |
| `_data` | 行数 ＝ CSV 工程数、工程ID が全件一致 |
| 保護 | シート保護が有効、C/D 以外がロック |

**目視**は、PDF・PNG と並べて「同じ行に同じ名前、同じ日付範囲にバー」を監督が確認する。目視は最終確認であり、開発ループの合否は上表で決める。

## 7. 操作手順（`使い方` シートに書く内容）

1. ZIP を右クリック → プロパティ → 「許可する」→ 展開
2. xlsm を開き、マクロを有効化
3. `00_Control` の「CSV 選択」で CSV を選ぶ
4. Start / End を入力（既定：CSV メタの期間の先頭から 40 日）
5. 「変換実行」
6. 同じフォルダーに xlsx と 変換ログ.txt ができる。ログ末尾が「合格」であることを確認
7. xlsx を業者へ送る

---

## 8. 受け入れ試験（実装セッションが自分で通すこと）

1. サンプル CSV、Start=2026/09/01、End=2026/10/10 で変換 → 6 章の検査が全件合格
2. Start=2026/09/01、End=2026/09/30 で変換 → 期間外除外がログに出る（10 月の工程）
3. Start=2026/09/15、End=2026/10/10 で変換 → クリップされる工程の開始列が 9/15 になる
4. 出力 xlsx を**マクロ無効の Excel**で開いて、C/D を編集できる、他は編集できない
5. 出力 xlsx をスマホの Excel で開いて、行見出し・バー・日付が読める（スクリーンショットを実装メモに添付）
6. CSV の工程行を 1 本コピーして 24 本にしたもので変換 → 停止せず 24 本描く（固有値埋め込みが無いことの確認）
