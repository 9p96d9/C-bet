## 使い方

`プロジェクトG_工程表ツール.html` をブラウザで開き、CSV を選んで［描画］。
SVG 検査が全件 OK になると［xlsx 書き出し］が有効になる。

**CSV に値が無く、ツールが規則で埋めた箇所は読み込みのたびに一覧で出る。**
「推定」と出た行は CSV から決められない値なので、プロジェクトG の画面で確認してほしい。
gate の中間行は「gate 中間行の指定」に `<工程ID>:<行>` を入れれば上書きできる。

## 工程表の絵はどこから来ているか

**CSV の値だけから、その場で描いています。** 渡した PDF を貼っているのではありません。

- HTML の中に画像は 1 枚も入っていない（`<image>`・`data:image`・PNG/JPEG・PDF のいずれも 0 件）。
  内訳は ExcelJS が 949KB、自前コードが 79KB、HTML と CSS が 5KB。
- 描画は `src/03-render.js` が `document.createElementNS` で
  `<path>` `<polygon>` `<rect>` `<circle>` `<text>` を組み立てている。
  座標はすべて CSV の日付・行番号から `x = 日付index × DAY_W`、
  `y = (行−1) × ROW_H + ROW_H/2` で計算する。
- PDF は **開発時に描画規則を実測するため**と、
  **`tools/compare-pdf.py` が答え合わせに使うため**にだけ登場する。
  ツール本体（HTML）は PDF を読まないし、同梱もしていない。

自分で確かめるには、CSV の値を変えて読み込み直せばよい。
例：A1 の `開始日`/`終了日` を 10 日ずらし、`工程線の色` を緑、`工程線の太さ` を 6 にすると、

| | 元の CSV | 書き換えた CSV |
|---|---|---|
| A1 の日付 | 2026-09-07〜09-14 | 2026-09-17〜09-24 |
| 最初の区間の `d` | `M 144 210 …` | `M 384 210 …`（10 日 × 24px = 240px 右） |
| 線色・太さ | `#ec635e` / 1.5 | `#00a000` / 6 |

結果は `out/demo_CSVを書き換えた描画_full.png`。A1 が緑の太い矢印になって右へ動き、
つながっていた A2 のノードから離れているのが分かる。
表示期間や 1 日の幅を変えても、SVG の幅と座標がそのつど計算し直される
（例：9/24–10/5・1 日 48px なら幅 576px、描画 11 件）。

## 別の工程表の CSV でも動くか

**同じ製品が出した CSV なら動きます。** 実際に変種を作って通しました
（`node tools/robustness-test.mjs`、14 件すべて期待どおり）。

| 変えたところ | 結果 |
|---|---|
| 列順を逆にした | 動く（列は見出し名で引いているため） |
| 使わない列を 52 個削った（124 → 72 列） | 動く |
| 知らない列を 5 個足した（124 → 129 列） | 動く |
| 必須列（`工程線の形状`）が無い | **読み込みで止まり、欠けている列名を出す** |
| BOM 無し・改行が LF | 動く |
| 別の年（2028 年） | 動く |
| 工程 230 件・行 460 | 動く（569ms、SVG 検査 3237 項目も全件 OK） |
| 工程 1 件／0 件 | 動く |
| `0.5日` に値がある | 動く（**警告**を出し、日付だけで描く） |
| `工程削除` に値がある | 動く（その工程を描かない） |
| `textSize = S`（サンプルに無い） | 動く（**推定として記録**される） |
| `crank` に中間ノードがある（サンプルに無い） | 動く |
| 知らない形状名 | 動く（直線として描き、警告を出す） |
| 関係線が 3 本 | 動く |
| **`休日` 列が自前の計算と食い違う** | **検査が拾って xlsx 書き出しを止める** |

### 別の工程表で注意がいるところ

1. **会社休日・祝日以外の休みがある工程表**
   本ツールは休日を「土日＋日本の祝日」で計算し、CSV の `休日` 列で検算する。
   食い違うと検査が NG になり、**xlsx 書き出しボタンが無効のまま**になる。
   黙って違う絵を出すよりは止める方を選んだ。その工程表を扱うには
   休日の規則を足す必要がある（`src/00-holiday.js` の 1 箇所）。

2. **`gate` の中間ノードの行**
   CSV にこの行番号が無いのはサンプル固有の話ではないので、
   **gate が多い工程表ほど推定が増える**。サンプルは 5 本中 2 本だったが、
   230 件に増やした試験では 20 本が推定になった。
   推定は全部一覧に出るので、画面の「gate 中間行の指定」で潰せる。

3. **`textSize = S` の実寸**
   サンプルに 1 件も無いため測れていない。使われていたら推定として記録される。

```
node tools/make-fixture.mjs               # 合成 CSV（禁止事項 1 の確認用）
node tools/build-html.mjs                 # src/ → プロジェクトG_工程表ツール.html
python3 tools/pdf-extract.py              # PDF からベクター座標を抜く
node tools/build-memo.mjs                 # docs/memo-body.md → 設計B_実装メモ.md
```

`プロジェクトG_工程表ツール.html` は生成物。直さずに `src/` を直して再ビルドすること。
