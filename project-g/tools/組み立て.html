組み立て・分解

組み立て＝ src/ の中身から納品用の単一 HTML を作る。
分解＝ 単一 HTML を src/ のファイルに戻す。
どちらもこのページの中だけで終わります。Node も、インターネットも要りません。

1. 分解する（単一 HTML → src/ のファイル）

手元に単一 HTML しか無いときに使います。中の 8 つの JS と shell.html と ExcelJS を取り出して、zip にまとめて保存します。

ここに プロジェクトG_工程表ツール.html を落とすか、下から選んでください

2. 組み立てる（src/ のファイル → 単一 HTML）

直した src/*.js を納品用の 1 枚に戻します。
いる物：src/shell.html、src/00-holiday.js 〜 src/07-diag.js の 8 本、 vendor/exceljs.min.js、vendor/exceljs.LICENSE。
フォルダごと落としても、ファイルをまとめて選んでも構いません（場所ではなく名前で見分けます）。
