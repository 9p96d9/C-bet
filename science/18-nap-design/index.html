昼寝の設計 — 何回・どれくらい、いつ手放すか

昼寝は午前の学びを固定し、情動を立て直す作業時間。月齢ごとの目安は幅で捉え、個人差を前提に「その子のリズム」に合わせる。

睡眠と記憶の章で見たとおり、寝ている間に脳は日中の経験を整理・保存します。この章はその実践編——昼寝をどう設計するかです。寝かしつけの手技そのものは日々の育児の積み重ねですが、「昼寝は何回・どれくらいが目安か」「いつ手放すのか」を知っておくと、父も家庭のリズムづくりに貢献できます。

まず大前提を一つ。以下に示す数値はすべて幅を持った目安であり、個人差は非常に大きい。表の中央値からずれていても、機嫌よく過ごし・成長曲線に沿っていれば、多くは心配いりません。

月齢ごとの目安（幅で捉える）

月齢1日の総睡眠（昼寝含む）昼寝の回数の目安
0〜3ヶ月14〜17時間不規則・多数（昼夜の区別がまだ弱い）
4〜11ヶ月12〜16時間2〜3回 → 後半で2回へ
1〜2歳11〜14時間1〜2回（多くは1歳半前後で1回へ）
3歳ごろ10〜13時間1回（この頃から昼寝を手放す子も出てくる）

::: evidence B 総睡眠時間の目安は WHO・米国小児科学会（AAP）・睡眠関連学会などの公的ガイドラインに基づく推奨レンジ。「この時間でなければ発達に悪い」という厳密な閾値ではなく、健康な子どもの分布に基づく目安。昼寝回数はさらに個人差が大きい。

:::

昼寝が果たしている役割（実践面）

夜の睡眠が学びを固定するのと同じ働きを、昼寝も担います。ただ実生活で父が実感しやすいのは、昼寝の"情動を立て直す"効果の方かもしれません。

🧠 科学的根拠 昼寝と記憶・情動

昼寝をとった乳幼児は、直前に学んだことをよりよく保持するという実験結果が複数あります。乳幼児は記憶の一時保管庫（海馬）の容量が小さいため、こまめに寝て「保存」する必要があるのではないかと考えられています。加えて、睡眠が足りている子は欲求不満に対する反応が穏やかで、足りないと些細なことでかんしゃくを起こしやすい傾向が報告されています。昼寝は午後の実行機能——注意・自己制御——を保つための"充電"でもあるのです。

::: evidence C 記憶固定・情動調整における昼寝の機序は、実験研究と理論に支えられているが、規模は限定的で個人差も大きい。「昼寝を1回逃したら学びが失われる」といった強い主張はできない。

:::

昼寝を守り、整える

👨 父ができること 昼寝を守る係になる
  • 午前中にしっかり動かす。 外遊び・体を使う遊びで適度に疲れると入眠しやすい。外遊びは昼寝の質にも効く。
  • 入眠前は興奮させて終わらない。 就寝前と同じで、ラフ＆タンブルのような激しい遊びは昼寝直前を避け、静かな流れで締める。
  • 暗さ・静かさ・決まった合図。 夜より簡略でよいが、カーテンを閉める・同じ絵本など「これから寝る」の合図があると入りやすい。
  • 休日に昼寝を潰さない。 お出かけで昼寝を飛ばした日の夕方の荒れは、疲れすぎのサイン。予定より子のリズムを優先できるのは、余裕のある側の親の仕事。

移行期 — 昼寝が減る・なくなる時期

昼寝の回数が減る移行期は、一時的にリズムが乱れます。2回→1回（多くは1歳〜1歳半ごろ）、1回→0回（多くは3〜5歳、幅が非常に広い）の切り替え時期です。

移行のサインは、寝つきが悪くなる・昼寝を嫌がる・昼寝すると夜眠れない、など。ただし早すぎる卒業は、夕方の極端な機嫌の悪化を招きます。回数を減らす前に、まず1回あたりを長くという順で調整すると急激な不足を避けやすい、とされます（等級C、経験則に近い）。

⚠️ 注意 夕方寝（夕寝）の扱い

夕方遅く（目安として16〜17時以降）の長い昼寝は、夜の入眠を後ろにずらしがちです。夕方にどうしても眠そうなときは、就寝を少し早める方が、遅い夕寝で夜更かしになるより整いやすいことが多い。ただしこれも一律のルールではなく、その子の翌朝の様子で調整します。

📌 要点

昼寝は「サボり」でも「早く卒業するほど偉い」ものでもありません。午前の学びを保存し、午後の自己制御を支える作業時間です。数値の目安は幅で捉え、表の平均より目の前の子のリズムを信じる——これが昼寝設計の芯です。
