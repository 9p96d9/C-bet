📚付録

月齢別・父のクイックリスト

「今週なにをすればいい？」に一枚で答えるための要約です。詳細は各月齢ロードマップへ。チェックは"達成度の採点"ではなく"やることの思い出し"に使ってください。

0〜3ヶ月

  • 毎日、顔を20〜30cmに近づけて話しかけた（parentese）
  • 泣き・声・視線に素早く応じた（サーブ＆リターン）
  • 起きている時間に短いうつ伏せ遊びをした
  • 子守唄・鼻歌を歌った（上手さ不問）
  • 父の担当場面（沐浴・散歩等）を1つ以上、毎日続けた

3〜6ヶ月

  • 声が出たら、まねして返す「音のラリー」をした
  • 手が届きそうな距離に玩具を置き、リーチングを引き出した
  • 床で自由に動ける時間を毎日確保した（床の自由）
  • 鏡・いないいないばあで一緒に笑った
  • 感触の違う物をいくつか握らせた

6〜12ヶ月

  • 指さし・視線の先を一緒に見て名づけた（指さし応答）
  • はいはい・つかまり立ちを安全な環境で自由にさせた
  • 「落とす・出す・入れる」の実験に根気よく付き合った
  • 絵本を毎日ひらいた（かじられても気にしない）
  • 人見知りで拒まれても、淡々と関わり続けた

12〜18ヶ月

  • 一語を拡張して返した（「ブーブー」→「赤いブーブーだね」）
  • 歩行・段差・斜面など多様な地形を経験させた
  • なぐり書き・積み木・スプーンの「じぶんで」を見守った
  • 一段階のおつかいミッションを楽しんだ
  • かんしゃくに、まず気持ちの言葉で応じた

18〜24ヶ月

  • ごっこ遊びに役として参加した（ごっこ）
  • 対話的読み聞かせで「問い→答え→広げる」をした
  • 走る・登る・投げる・蹴るをまんべんなく遊んだ
  • 「あと1回でおしまい」の予告つき切り替えを実践した
  • 2択で選ばせる場面を作った

24〜36ヶ月

  • 「なぜ？」「これなに？」に付き合い、一歩広げて返した
  • 数える・分ける・形さがしを生活に混ぜた（おやつの分配）
  • ルールのある遊び（ダンス＆ストップ等）をした
  • お手伝い（配膳・料理・洗濯）を「係」として任せた
  • 初めての場所への週末ミニ冒険をした

全期間・毎週の自問（父自身のチェック）

  • スマホを置いて全部応答する時間を、今日も数分作れたか
  • 「できた/できない」でなく、楽しかったかで一日を振り返れたか
  • 妻と方針・発見を共有したか。妻の休む余白を作れたか
  • 比較・焦り・煽り（SNS・広告）に引きずられていないか

父の"設備投資"はモノより場所と時間

  • 図書館カード — 蔵書は借りて増やす（図書館の日）
  • 行ける公園のリスト — 地形・遊具の違う公園を数カ所開拓（週末ミニ冒険）
  • 汚れてよい服と着替え — 「汚れるからダメ」を減らす準備
  • 床の安全なスペース — 最強の遊具は自由に動ける床（環境デザイン）
⚠️ 注意 買う前のチェック

「光る・鳴る・しゃべる」機能が多いほど、子の側の仕事が減ります。買う前に「この玩具、子どもが90%働くか？」と自問を（→ 玩具の選び方）。

用語集

相性（適合の良さ）
子の気質と、環境・親の関わり・求められることが噛み合っている度合い。「育てにくさ」は気質そのものより、この相性の問題。
関連: 気質 / 足場かけ（スキャフォールディング）
足場かけ（スキャフォールディング）
子が一人では難しいが手助けがあればできる課題を、少し支えながら挑戦させる関わり。発達の最近接領域を活かす。
関連: 実行機能（EF）
アタッチメント（愛着）
子と養育者の間に築かれる情緒的な絆。安全基地となり、探索・学習・自己制御の土台になる。
関連: 安全基地 / サーブ＆リターン
安全基地
子が安心して世界を探索し、不安になれば戻れる拠り所となる養育者の役割。愛着が安定すると機能する。
関連: アタッチメント
アンダーマイニング効果
もともと好きな活動に物的報酬（シール・お菓子）を持ち込むと、かえって内発的な興味が下がる現象。遊びやお手伝いに報酬を混ぜない根拠。
移行（トランジション）
遊びを終える・家を出る・入浴する・寝るなど、場面が切り替わる瞬間。一日で最も荒れやすく、予告・儀式・「次」の提示で負荷を下げられる。
関連: 予測可能性 / 情動調整
移行対象
お気に入りの布・ぬいぐるみなど、親の代わりに安心を持ち運べる物。分離の場面や入眠時に自分を落ち着かせる道具になる。
関連: 分離不安（8ヶ月不安）
1対1対応
物と物、物と数詞を一つずつ対応させること。「一人に一つ配る」がその体験で、数唱の暗記より数の意味の核心にある。
関連: 数量感覚 / 基数性
移動系動作と操作系動作
基礎的動作スキルの2系統。走る・跳ぶ・登るなど体を移動させる動作と、投げる・捕る・蹴るなど物に働きかける動作。幼児期は上手さより種類を増やす。
関連: 基礎的動作スキル（FMS） / ABC（運動）
ヴィデオ・デフィシット
2歳未満の乳児が、同じ内容を対面より動画からは学びにくい現象。乳児向け知育動画の効果が乏しい理由。
関連: スクリーンタイム
ABC（運動）
Agility（敏捷性）・Balance（バランス）・Coordination（協応）。幼児期の運動で育てたい3要素。
関連: 基礎的動作スキル（FMS）
エビデンスレベル
主張の確からしさの等級（本資料ではA〜D）。Aが最も強く、Dは人気だが根拠が薄い。
おもちゃのローテーション
一度に出す玩具を少数に絞り、数週ごとに入れ替える運用。選択肢を減らすことで遊びが深く長くなり、片づけも成立しやすい。
関連: ルーズパーツ / スクリーンタイム
音韻意識
言葉が音のかたまりでできていると気づく力（拍・韻・頭の音）。文字を音に変換する読みの前提で、しりとり・韻遊びで育つ。
関連: 対話的読み聞かせ / 言語のシャワー
拡張（エクスパンション）
子の発話に1〜2語だけ足して返す関わり（子「ブーブー」→「あかい ブーブーだね」）。訂正せず、少し上の形を渡すのが要点。
関連: サーブ＆リターン / 足場かけ（スキャフォールディング）
可塑性（脳の）
経験に応じて脳が自らの配線を変える力。乳幼児期に最も高く、学びの土台。回復力の源でもある。
関連: シナプスの刈り込み / 髄鞘化（ミエリン化）
感覚過敏・感覚探求
刺激を強く感じすぎる傾向と、強い刺激を自分から求める傾向。感覚ごとに異なることも多く、無理な慣らしより刺激量の調整で合わせる。
関連: 感覚統合 / 気質 / 相性（適合の良さ）
感覚統合
視覚・聴覚・触覚・運動などの感覚を脳でまとめ意味づける働き。多感覚の一致した経験で育つ。
関連: 前庭感覚 / 固有感覚
気質
刺激への反応や感情の出方の、生まれつきの傾向（活発さ・敏感さ・順応性など）。良し悪しはなく、環境との相性で表れ方が変わる。
関連: 相性（適合の良さ） / 差次感受性
基数性
数えたときの「最後に言った数＝全体の個数」だと分かること。数唱が意味を持つための鍵。
関連: 数量感覚 / サビタイジング
基礎的動作スキル（FMS）
走る・跳ぶ・投げる・捕る・蹴る・バランスなど、あらゆるスポーツの土台となる基本動作。幼児期に幅広く育てる。
関連: 身体リテラシー / ABC
共同注意
子と大人が同じ対象に注意を向け合うこと。指さしや視線追いで成立し、語彙獲得の重要な土台。
関連: サーブ＆リターン / 言語のシャワー
空間認知
形・位置・向き・大きさを頭の中でイメージして操作する力。積む・回す・空間のことばで育ち、後の数学・STEMと関連する。
関連: 数量感覚
言語のシャワー
子が日常で浴びる言葉の量と質。後の語彙・読解・学業と関連する。応答的な語りかけが鍵。
関連: サーブ＆リターン / 共同注意
限定された選択
大人が選択肢を2〜3に絞り、その中から子に決めさせる関わり。決める負荷を下げつつ自律感を保ち、かんしゃくの予防にもなる。
関連: 実行機能（EF）
語彙爆発
おおむね18〜24ヶ月に、新しい語を急速に取り込み始める時期。開始時期の個人差は大きく、二語文へつながる。
関連: 理解語彙と産出語彙 / 言語のシャワー
固有感覚
体の位置や力加減を捉える感覚。押す・引く・持ち上げる経験で体の"地図"が精緻になる。
関連: 前庭感覚
サーブ＆リターン
子の発信に養育者が即座に意味を持って応じる往復のやりとり。神経回路形成の基本単位で、最も根拠の強い関わり。
関連: アタッチメント / 共同注意
差次感受性
敏感な子ほど、悪い環境では傷つきやすい一方、良い環境ではむしろ人一倍伸びやすいという考え方（「タンポポとラン」）。検証途上（等級C）。
関連: 気質 / 相性（適合の良さ）
サビタイジング
2〜3個程度なら、数えずにパッと個数が分かる力。数と量が結びつき始めたサイン。
関連: 数量感覚 / 基数性
実行機能（EF）
ワーキングメモリ・抑制制御・認知的柔軟性からなる"脳の司令塔"。学業成功の強力な予測因子。
関連: ワーキングメモリ / 足場かけ
シナプスの刈り込み
過剰に作られた神経結合のうち、使われないものを整理する過程。経験がどの回路を残すかを決める。
関連: 可塑性
社会的参照
新しい物事に出会ったとき養育者の表情を確認し行動を決めること。9〜12ヶ月ごろ明確になる。
関連: アタッチメント（愛着） / 安全基地
情動調整
感情を認識し落ち着ける力。学業・人間関係の土台で、実行機能と深く重なる。名づけと受容で育つ。
関連: 実行機能（EF） / 毒性ストレス
信号対雑音比（音環境）
聞きたい音と背景音の比。BGMやつけっぱなしのテレビはこの比を下げ、語の切り出しと弁別を難しくする。
関連: 言語のシャワー / スクリーンタイム
身体図式
自分の体の位置・大きさ・動きについての脳内の地図。道具を使うとき、脳は道具の先端まで体の一部のように扱う（図式の拡張）。
関連: 固有感覚 / 感覚統合
身体的有能感
「自分は体を動かすのが得意」という自己認識。運動継続と技能向上の好循環を生む。成功体験で育つ。
関連: 身体リテラシー / 早期特化
身体リテラシー
多様な動作を自信を持って楽しめる能力と意欲。特定競技より優先して幼児期に育てるべきもの。
関連: 基礎的動作スキル（FMS）
髄鞘化（ミエリン化）
神経の軸索に絶縁体ミエリンが巻かれ信号伝達が高速化する過程。幼児期から10代以降までゆっくり続く。
関連: 可塑性（脳の）
数量感覚
数と量を意味として直感的につかむ力（多い/少ない、いくつ）。生まれつきの近似数感覚を、言葉と経験で磨く。数唱（暗唱）とは別物。
関連: サビタイジング / 基数性
スクリーンタイム
画面を見て過ごす時間。0〜2歳では多感覚性と応答性を欠くため学びに乏しく、やりとり・外遊び・睡眠を削らないかで見る。
関連: ヴィデオ・デフィシット
前庭感覚
傾き・回転・加速を捉える感覚。姿勢制御・バランス・空間で自分を捉える力の土台。揺れ・高低の遊びで育つ。
関連: 固有感覚 / 感覚統合
早期特化
幼少から一競技に絞る訓練。多くの競技で障害・燃え尽きと関連し不利になりうる。幼児期は多様化が原則。
関連: 身体リテラシー / 基礎的動作スキル（FMS）
相対年齢効果
同学年内の月齢差で、早生まれがやや不利に見える現象。成熟の差であって能力差ではなく、学年とともに縮小する。
退行（赤ちゃん返り）
大きな環境変化のあと、できていた行動が一時的に前の段階へ戻る現象。不安への正常な適応で、叱責より安心の供給を増やすと早く戻る。
関連: 分離不安（8ヶ月不安） / 毒性ストレス
対象の永続性
見えなくなった物や人が、存在し続けていると分かる力。生後半年ごろから育ち、いないいないばあが楽しくなる理由であり、分離不安の前提でもある。
関連: 分離不安（8ヶ月不安）
対乳児発話（parentese）
赤ちゃんに向かうと自然に出る、高め・大きな抑揚・ゆっくり・はっきりの話し方。文法は正しいまま。注意と音の学習を助ける。
関連: 言語のシャワー / サーブ＆リターン
対話的読み聞かせ
読み上げるだけでなく問いかけ、子の答えを広げる読み聞かせ法。語彙と読解の前駆スキルに効果的。
関連: 言語のシャワー
多重愛着
子が母・父・祖父母・保育者それぞれと同時に、独立した愛着関係を築くこと。愛着は取り合う有限の資源ではなく、続く関係の本数が資産になる。
関連: アタッチメント（愛着） / 安全基地
脱文脈の会話
今ここにない出来事（過去・未来・想像）を言葉で語る会話。物語る力を育て後の読解・作文と関連。
関連: 言語のシャワー / 対話的読み聞かせ
知覚の絞り込み
母語で使う音の対比だけを残し、使わない対比の弁別が弱まる乳児期の現象。生後6〜12ヶ月ごろ。
関連: 臨界期 / 敏感期
父親の産後うつ
出産後の時期に父親が経験する抑うつ状態（おおむね8〜10%程度と報告）。落ち込みよりいらだち・引きこもり・飲酒の増加として出やすい。
関連: 毒性ストレス
毒性ストレス
強く長期にわたり、支えとなる大人がいない中で受けるストレス。脳の発達を妨げる。応答的な関係が緩衝材になる。
関連: アタッチメント
パターン認識
くり返しの規則に気づき、続ける力（赤・青・赤・青…）。代数的思考の萌芽とされ、手拍子や並べる遊びで育つ。
関連: 分類（カテゴリー化）
敏感期
特定の学習が起こりやすい時期。ただし過ぎても学習は可能で、窓は閉じない。多くの能力はこちら。
関連: 臨界期
ピンサーグリップ
親指と人差し指の先で小さな物をつまむ精密な握り。おおむね生後9〜12ヶ月で獲得し、自分で食べる・道具使用の入り口。
関連: 基礎的動作スキル（FMS）
賦活の関係
子を探索・挑戦へ押し出す関わり。父親に多く観察され、安全基地（戻る安心）と相補的に働く。
関連: 安全基地 / アタッチメント（愛着）
ふり遊び（象徴遊び）
目の前にない物・場面を思い描いて演じる遊び。言語・自己制御・他者理解・抽象化を同時に育てる。見立て→役割ごっこと発達する。
関連: 実行機能（EF） / 足場かけ（スキャフォールディング）
プリント・アウェアネス
本は左から開く、文字が意味を持つ、といった書かれた言葉についての気づき。読字の前駆スキルの一つで、読み聞かせの中で自然に育つ。
関連: 音韻意識 / 対話的読み聞かせ
分離不安（8ヶ月不安）
特定の相手と離れることへの強い不安。8ヶ月前後から現れ、愛着が形成された証拠。「戻ってくる」の見通しが育つにつれ落ち着く。
関連: アタッチメント（愛着） / 対象の永続性 / 移行対象
分類（カテゴリー化）
色・形・用途などの属性で物をまとめる働き。「同じ仲間」と判断できることが、数える・語彙を獲得する前提になる。
関連: パターン認識 / 1対1対応
並行遊び
隣で同じような遊びを別々にする段階。2〜3歳の主役で、協同遊びの前段階。見て・まねる社会学習が進む時間であり、社会性の不足ではない。
関連: ふり遊び（象徴遊び）
保育の質
担当者の安定性・大人一人あたりの子どもの数・応答的な関わり・言葉かけの豊かさなどで捉える指標。在園時間の長短より、この質のほうが結果と関連する。
関連: 多重愛着 / サーブ＆リターン
満足の遅延
今すぐの報酬を待って、より良い結果を得る力。我慢の強さより、気そらしなどの方略と「約束が守られる環境」に大きく左右される。
関連: 実行機能（EF）
予測可能性
次に何が起きるか子が見通せること。ストレス反応を下げ、切り替えの抵抗を減らす。時刻の厳密さより、順序と関わり方の一定さで作られる。
関連: 毒性ストレス / 移行（トランジション）
ラフ＆タンブル遊び
取っ組み合いなど活発な身体遊び。父親に多く、興奮の調整・体の制御・社会性を育てる。
関連: 前庭感覚 / 情動調整
理解語彙と産出語彙
聞いて分かる語（理解）と、自分で言える語（産出）。理解は産出に先行し、話さない時期にも理解と身ぶりは育っている。
関連: 語彙爆発 / 共同注意
リスクのある遊び
登る・高い所から跳ぶ・スピードを出すなど、適度な危なさを含む遊び。体の使い方・危険の見積もり・自信を育てる。過保護と無謀の間を設計する。
関連: 前庭感覚 / ラフ＆タンブル遊び
臨界期
その時期を過ぎると学習が極めて困難になる発達の窓。視覚や第一言語の音韻など一部に限られる。
関連: 敏感期
ルーズパーツ
使い方が決まっておらず、動かし組み合わせられる素材（箱・布・石・容器など）。発明と発見の機会を増やすオープンエンドな遊びの核。
関連: 足場かけ（スキャフォールディング）
ワーキングメモリ
情報を一時的に保持しながら操作する能力。実行機能の中核で、暗算や指示の記憶に使う。
関連: 実行機能（EF）
