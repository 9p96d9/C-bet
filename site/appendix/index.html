📚付録

月齢別・父のクイックリスト

「今週なにをすればいい？」に一枚で答えるための要約です。詳細は各月齢ロードマップへ。チェックは"達成度の採点"ではなく"やることの思い出し"に使ってください。

0〜3ヶ月

  • 毎日、顔を20〜30cmに近づけて話しかけた（parentese）
  • 泣き・声・視線に素早く応じた（サーブ＆リターン）
  • 起きている時間に短いうつ伏せ遊びをした
  • 子守唄・鼻歌を歌った（上手さ不問）
  • 父の担当場面（沐浴・散歩等）を1つ以上、毎日続けた

3〜6ヶ月

  • 声が出たら、まねして返す「音のラリー」をした
  • 手が届きそうな距離に玩具を置き、リーチングを引き出した
  • 床で自由に動ける時間を毎日確保した（床の自由）
  • 鏡・いないいないばあで一緒に笑った
  • 感触の違う物をいくつか握らせた

6〜12ヶ月

  • 指さし・視線の先を一緒に見て名づけた（指さし応答）
  • はいはい・つかまり立ちを安全な環境で自由にさせた
  • 「落とす・出す・入れる」の実験に根気よく付き合った
  • 絵本を毎日ひらいた（かじられても気にしない）
  • 人見知りで拒まれても、淡々と関わり続けた

12〜18ヶ月

  • 一語を拡張して返した（「ブーブー」→「赤いブーブーだね」）
  • 歩行・段差・斜面など多様な地形を経験させた
  • なぐり書き・積み木・スプーンの「じぶんで」を見守った
  • 一段階のおつかいミッションを楽しんだ
  • かんしゃくに、まず気持ちの言葉で応じた

18〜24ヶ月

  • ごっこ遊びに役として参加した（ごっこ）
  • 対話的読み聞かせで「問い→答え→広げる」をした
  • 走る・登る・投げる・蹴るをまんべんなく遊んだ
  • 「あと1回でおしまい」の予告つき切り替えを実践した
  • 2択で選ばせる場面を作った

24〜36ヶ月

  • 「なぜ？」「これなに？」に付き合い、一歩広げて返した
  • 数える・分ける・形さがしを生活に混ぜた（おやつの分配）
  • ルールのある遊び（ダンス＆ストップ等）をした
  • お手伝い（配膳・料理・洗濯）を「係」として任せた
  • 初めての場所への週末ミニ冒険をした

全期間・毎週の自問（父自身のチェック）

  • スマホを置いて全部応答する時間を、今日も数分作れたか
  • 「できた/できない」でなく、楽しかったかで一日を振り返れたか
  • 妻と方針・発見を共有したか。妻の休む余白を作れたか
  • 比較・焦り・煽り（SNS・広告）に引きずられていないか

道具・素材リスト

本資料の実践図鑑に登場する道具の総覧です。原則は一つ——高価な知育玩具は要りません（→ 玩具の選び方）。

父の"設備投資"はモノより場所と時間

  • 図書館カード — 蔵書は借りて増やす（図書館の日）
  • 行ける公園のリスト — 地形・遊具の違う公園を数カ所開拓（週末ミニ冒険）
  • 汚れてよい服と着替え — 「汚れるからダメ」を減らす準備
  • 床の安全なスペース — 最強の遊具は自由に動ける床（環境デザイン）
⚠️ 注意 買う前のチェック

「光る・鳴る・しゃべる」機能が多いほど、子の側の仕事が減ります。買う前に「この玩具、子どもが90%働くか？」と自問を（→ 玩具の選び方）。

用語集

足場かけ（スキャフォールディング）
子が一人では難しいが手助けがあればできる課題を、少し支えながら挑戦させる関わり。発達の最近接領域を活かす。
関連: 実行機能（EF）
アタッチメント（愛着）
子と養育者の間に築かれる情緒的な絆。安全基地となり、探索・学習・自己制御の土台になる。
関連: 安全基地 / サーブ＆リターン
安全基地
子が安心して世界を探索し、不安になれば戻れる拠り所となる養育者の役割。愛着が安定すると機能する。
関連: アタッチメント
ヴィデオ・デフィシット
2歳未満の乳児が、同じ内容を対面より動画からは学びにくい現象。乳児向け知育動画の効果が乏しい理由。
関連: スクリーンタイム
ABC（運動）
Agility（敏捷性）・Balance（バランス）・Coordination（協応）。幼児期の運動で育てたい3要素。
関連: 基礎的動作スキル（FMS）
エビデンスレベル
主張の確からしさの等級（本資料ではA〜D）。Aが最も強く、Dは人気だが根拠が薄い。
可塑性（脳の）
経験に応じて脳が自らの配線を変える力。乳幼児期に最も高く、学びの土台。回復力の源でもある。
関連: シナプスの刈り込み / 髄鞘化（ミエリン化）
感覚統合
視覚・聴覚・触覚・運動などの感覚を脳でまとめ意味づける働き。多感覚の一致した経験で育つ。
関連: 前庭感覚 / 固有感覚
基礎的動作スキル（FMS）
走る・跳ぶ・投げる・捕る・蹴る・バランスなど、あらゆるスポーツの土台となる基本動作。幼児期に幅広く育てる。
関連: 身体リテラシー / ABC
共同注意
子と大人が同じ対象に注意を向け合うこと。指さしや視線追いで成立し、語彙獲得の重要な土台。
関連: サーブ＆リターン / 言語のシャワー
言語のシャワー
子が日常で浴びる言葉の量と質。後の語彙・読解・学業と関連する。応答的な語りかけが鍵。
関連: サーブ＆リターン / 共同注意
固有感覚
体の位置や力加減を捉える感覚。押す・引く・持ち上げる経験で体の"地図"が精緻になる。
関連: 前庭感覚
サーブ＆リターン
子の発信に養育者が即座に意味を持って応じる往復のやりとり。神経回路形成の基本単位で、最も根拠の強い関わり。
関連: アタッチメント / 共同注意
実行機能（EF）
ワーキングメモリ・抑制制御・認知的柔軟性からなる"脳の司令塔"。学業成功の強力な予測因子。
関連: ワーキングメモリ / 足場かけ
シナプスの刈り込み
過剰に作られた神経結合のうち、使われないものを整理する過程。経験がどの回路を残すかを決める。
関連: 可塑性
社会的参照
新しい物事に出会ったとき養育者の表情を確認し行動を決めること。9〜12ヶ月ごろ明確になる。
関連: アタッチメント（愛着） / 安全基地
情動調整
感情を認識し落ち着ける力。学業・人間関係の土台で、実行機能と深く重なる。名づけと受容で育つ。
関連: 実行機能（EF） / 毒性ストレス
身体的有能感
「自分は体を動かすのが得意」という自己認識。運動継続と技能向上の好循環を生む。成功体験で育つ。
関連: 身体リテラシー / 早期特化
身体リテラシー
多様な動作を自信を持って楽しめる能力と意欲。特定競技より優先して幼児期に育てるべきもの。
関連: 基礎的動作スキル（FMS）
髄鞘化（ミエリン化）
神経の軸索に絶縁体ミエリンが巻かれ信号伝達が高速化する過程。幼児期から10代以降までゆっくり続く。
関連: 可塑性（脳の）
前庭感覚
傾き・回転・加速を捉える感覚。姿勢制御・バランス・空間で自分を捉える力の土台。揺れ・高低の遊びで育つ。
関連: 固有感覚 / 感覚統合
早期特化
幼少から一競技に絞る訓練。多くの競技で障害・燃え尽きと関連し不利になりうる。幼児期は多様化が原則。
関連: 身体リテラシー / 基礎的動作スキル（FMS）
対話的読み聞かせ
読み上げるだけでなく問いかけ、子の答えを広げる読み聞かせ法。語彙と読解の前駆スキルに効果的。
関連: 言語のシャワー
脱文脈の会話
今ここにない出来事（過去・未来・想像）を言葉で語る会話。物語る力を育て後の読解・作文と関連。
関連: 言語のシャワー / 対話的読み聞かせ
知覚の絞り込み
母語で使う音の対比だけを残し、使わない対比の弁別が弱まる乳児期の現象。生後6〜12ヶ月ごろ。
関連: 臨界期 / 敏感期
毒性ストレス
強く長期にわたり、支えとなる大人がいない中で受けるストレス。脳の発達を妨げる。応答的な関係が緩衝材になる。
関連: アタッチメント
敏感期
特定の学習が起こりやすい時期。ただし過ぎても学習は可能で、窓は閉じない。多くの能力はこちら。
関連: 臨界期
賦活の関係
子を探索・挑戦へ押し出す関わり。父親に多く観察され、安全基地（戻る安心）と相補的に働く。
関連: 安全基地 / アタッチメント（愛着）
ラフ＆タンブル遊び
取っ組み合いなど活発な身体遊び。父親に多く、興奮の調整・体の制御・社会性を育てる。
関連: 前庭感覚 / 情動調整
臨界期
その時期を過ぎると学習が極めて困難になる発達の窓。視覚や第一言語の音韻など一部に限られる。
関連: 敏感期
ワーキングメモリ
情報を一時的に保持しながら操作する能力。実行機能の中核で、暗算や指示の記憶に使う。
関連: 実行機能（EF）
