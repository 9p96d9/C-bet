❤️折れない心と共感の土台

感情を理解し調整できる力は、集中・粘り・人間関係——勉強とスポーツの両方の前提です。安心と受容の中でこそ育ちます。

🧠 まず読む（根拠）
  • 愛着 — すべての探索の安全基地
  • 毒性ストレスと緩衝材としての父親
  • 社会情動・共感ドメイン
  • 探索を促す「押し出す」関わり

0〜12ヶ月

B 中程度 0〜3歳 ⏱ 5分

わらべうた・韻あそび

「いっぽんばし」「げんこつやま」——リズムと繰り返しのわらべうたは、音韻意識とやりとりの宝庫。

読み聞かせ・リテラシー音楽・リズム・聴覚社会情動・共感 勉強に効く情緒
B 中程度 6ヶ月〜30ヶ月 ⏱ 5分

よびかけソング（コール＆レスポンス）

「やっほー」→「やっほー」と歌や声を呼びかけ合う。音のやりとりは会話の原型で、聴く力と発声を育てる。

音楽・リズム・聴覚言語・コミュニケーション社会情動・共感 勉強に効く情緒
B 中程度 0〜18ヶ月 ⏱ 5分

赤ちゃん語りかけ（parentese）

高めで抑揚豊かな、しかし正しい言葉での語りかけ。赤ちゃんの注意を引き、音の学習を助ける。

言語・コミュニケーション社会情動・共感 勉強に効く情緒
C 限定的 10ヶ月〜3歳 ⏱ 30分

手づくり写真絵本（じぶんだけの本）

家族や身近な物の写真でオリジナル絵本を作る。「自分が出てくる本」は関心が桁違いで、語りと読む意欲を引き出す。

読み聞かせ・リテラシー言語・コミュニケーション社会情動・共感 勉強に効く情緒
C 限定的 10ヶ月〜3歳 ⏱ 120分

週末ミニ冒険（初めての場所へ）

月に数回、行ったことのない公園・水辺・山道へ。新奇な環境は探索・語彙・感覚・運動をまとめて動かす。

好奇心・探索・遊び粗大運動・スポーツ視覚・感覚統合言語・コミュニケーション スポーツに効く創造性情緒
C 限定的 0〜2歳 ⏱ 3分

ひざでビート（拍にのる）

子を膝にのせ、歌や音楽の拍に合わせて上下にゆらす。一定の拍を体で感じる経験は、リズム感と聴覚の土台。

音楽・リズム・聴覚粗大運動・スポーツ社会情動・共感 情緒
C 限定的 0〜3歳 ⏱ 5分

子守唄（父の低い声で）

同じ子守唄を毎日そっと歌う。父の低い声は母と違う音色で、歌でつながる時間そのものが情緒と聴覚を育てる。

音楽・リズム・聴覚社会情動・共感言語・コミュニケーション 情緒
C 限定的 3ヶ月〜2歳 ⏱ 5分

鏡あそび

鏡の前で表情・体の部位を一緒に見る。自己認識と表情の学び、体の地図づくりの入り口。

視覚・感覚統合社会情動・共感言語・コミュニケーション 情緒
B 中程度 6ヶ月〜30ヶ月 ⏱ 5分

まねっこあそび

手を叩く・バンザイ・変な音——交互にまねし合う。模倣は社会学習のエンジンで、往復はサーブ＆リターンそのもの。

社会情動・共感粗大運動・スポーツ言語・コミュニケーション 情緒スポーツに効く
A 強い根拠 0〜3歳 ⏱ 5分

赤ちゃんの声・視線にすぐ応じ、見ているものを言葉にして返す。最強にして無料の言語＆愛着トレ。

言語・コミュニケーション社会情動・共感実行機能・自己制御 勉強に効く情緒
B 中程度 3ヶ月〜18ヶ月 ⏱ 3分
