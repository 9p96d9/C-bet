絵本の選び方と、続く読書習慣のつくり方

月齢に合う本の条件と、読み聞かせが続かないときの立て直し方。冊数より「毎日・短く・楽しい」を守る設計。

リテラシーの全体像はハブ、読み方の技術は対話的読み聞かせ（PEER・CROWD）、音で遊ぶ話は音韻意識にまとめました。この記事はどの本を選び、どう続けるかという運用の各論です（本棚など環境の設計は → 絵本と本棚の設計）。

月齢に合う本の条件

「良い絵本」は月齢によって変わります。大人の評価が高い本より、その子が今、反応する本が正解です。

月齢合う本の条件
0〜6ヶ月高コントラスト、大きな顔、丈夫な厚紙。内容より声のリズム
6〜12ヶ月かじれる素材、手ざわり・しかけ、擬音、1ページ1つの絵
12〜18ヶ月身近な物の名前、指さしできる絵、短い繰り返し
18〜24ヶ月くり返しの構造、リズムのある文、日常の場面
24〜36ヶ月短い物語（起承転結）、感情の出る話、なぜ？に答える本
📌 要点

共通するのは短いこと。最後まで読み切ることは目的ではありません。3ページで閉じても、それは失敗ではなく、その日の読書です。

選ぶときの実務的な基準

  • 子に選ばせる。 自分で選んだ本は集中が違います。図書館で2〜3冊を本人に選ばせる枠を作る（→ としょかんの習慣）。
  • 繰り返しに耐える本を。 何十回も読む前提で、親が飽きにくい本を選ぶのは正当な基準です。
  • 文字なし絵本を混ぜる。 語りを自分で作れるので、読み手の負担が下がり、子の発話は増えます（→ もじなし絵本で語る）。
  • しかけ本は"操作"が主役になりやすい。 悪くはありませんが、言葉のやりとりは減りがち。バランスで。
  • 音の楽しい本を持つ。 韻・オノマトペは音韻意識の入り口（→ 音韻意識）。
  • 同じ本を何度でも。 繰り返しは学びの本体です（→ 「同じ絵本ばかりは無意味」神話）。

続かないときの立て直し

読み聞かせが途切れる原因はだいたい決まっています。

🧠 科学的根拠 続く読書習慣は「量」より「頻度」

読み聞かせの効果は、一度の長さより頻度と、その時間が楽しいかどうかに左右されると考えられています。ページ数や冊数を目標にすると義務になり、子の側の抵抗も増える。逆に、毎日決まったタイミングで短く読むほうが、長期には累積量も上回ります（等級B）。

よくある詰まりと対処

  • 座って聞かない → 座らせなくてよい。動き回りながら聞いている子は聞いています。膝に乗せることにこだわらない。
  • ページを勝手にめくる → めくらせる。本のペースは子のもの。読み飛ばして構いません。
  • 同じ本ばかり → 歓迎する。回ごとに読み方を変える（指さす → 問う → 子に語らせる）。
  • すぐ飽きる → 3分で終える。短くていいので毎日に。
  • 時間が取れない → 寝る前1冊に固定する。読めない日は諦めてよく、翌日再開すれば十分です。
  • 父が読むと嫌がる → 母と同じ読み方を目指さない。声も間も違って当然で、別の楽しさとして成立します。

環境で続きやすくする

  • 本は表紙が見える低い棚に、少数だけ。全部並べると選べません（→ 本のコーナー）。
  • 読む場所を決める（同じソファ、同じクッション）。場所が合図になります。
  • 家中に本を散らす——寝室、車、かばん。手が届く距離が冊数より効きます。
  • 自作の本も強い。写真を貼っただけの手作り絵本は、市販本より食いつくことがあります（→ てづくり絵本）。
👨 父ができること 父の読み方でいい

棒読みでも、途中で脱線しても、勝手に話を作っても構いません。父の読みは母と声も間も違い、それ自体が言語入力の多様性になります。指さして名前を言うだけの「読み」でも十分です（→ ゆびさし読み）。

大事なのは1点だけ——テストにしないこと。「これ何色？」の連発は読書を試験に変えます。問うなら答えのない問いを（「このあとどうなると思う？」）。

⚠️ 注意 冊数を目標にしない

「年間◯冊」のような目標は、親の達成感には効きますが、子の読書への態度には効きません。この時期に育てているのは読解力ではなく、本は楽しいという構えです。そこを壊す運用は、どんなに冊数が積み上がっても損になります（→ 早期読み書きの神話）。

📌 要点

選書の基準は「短い・繰り返せる・子が選んだ」。運用の基準は「毎日・短く・楽しい」。読み切ることも冊数も、目標ではありません。
