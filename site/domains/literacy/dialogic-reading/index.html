対話的読み聞かせの実際 — 読み手が「聞き手」になる

対話的読み聞かせは根拠の強い方法だが、コツは「PEER」と「CROWD」という型にある。読み上げから対話へ切り替える具体的な問いかけを、月齢別に。

リテラシー前駆の全体像は 読み聞かせ・リテラシー前駆ハブ にまとめました。ハブでは「対話的読み聞かせが王道」と紹介しましたが、この記事はそのやり方の中身に踏み込みます。ポイントは、思いつきで質問することではなく、PEER と CROWD という2つの型にあります。

そもそも何が"対話的"なのか

📌 要点

ふつうの読み聞かせは「親が読む・子が聞く」。対話的読み聞かせは、これを逆転させ、少しずつ子を"語り手"の側に移すことを狙います。 最終的なゴールは、親が読み上げるより、子が絵を見て自分で語り出すこと。親の役割は、朗読者から聞き役・引き出し役へと移っていきます。

🧠 科学的根拠 根拠の強さと、その限界

対話的読み聞かせは、就学前の言語・語彙への効果が複数のランダム化比較試験とメタ分析で確認されている、早期リテラシー介入の中でも根拠の厚い方法です。一方で、効果量は中程度で、伸びやすいのは表出語彙（話す言葉）が中心。効果は家庭の言語環境や続けた量にも左右され、「これさえやれば読解力が保証される」わけではありません。だから本稿もハブのA評価に対し、家庭での運用の確実性を見て一段下げてBとしています。強い方法だからこそ、過大な期待ではなく"続く形"で使うのが要点です（→ 言語のシャワー）。

PEER：親のふるまいの型

1ページごとに、親はこの流れを回します。

  • P（Prompt / 促す） — 「これ、なあに？」「わんわん、何してる？」と子に問いを向ける。
  • E（Evaluate / 受け止める） — 答えを肯定的に受け止める。「そう、わんわんだね！」
  • E（Expand / 広げる） — 子の言葉に少し足して返す。「わんわん」→「大きい茶色のわんわんが走ってるね」（→ ひろげて返す）。
  • R（Repeat / くり返す） — 広げた言い方を子がまた言えるようそっと促す。

E（広げる）が心臓部です。子の一語を、二語・三語にして返す。これが語彙と文の伸びを作ります。

CROWD：問いかけの5種類

「なあに？」ばかりだと単調になります。5種類の問いを混ぜると、対話が立体的になります。

  • C（Completion / 穴埋め） — 決まり文句の途中で止める。「おおきな かぶを、うんとこしょ、どっこい…？」
  • R（Recall / 思い出し） — 前のページや読んだ話を思い出す。「さっき、だれが出てきたっけ？」
  • O（Open-ended / 自由） — 「この絵、どうなってると思う？」正解のない問い。
  • W（Wh- / 5W1H） — 「だれ・なに・どこ・なんで」。指さしとセットで（→ 指さし読み）。
  • D（Distancing / 生活とつなぐ） — 本の中身を子の経験に結ぶ。「〇〇も昨日、公園で滑り台したね」

Distancing（生活とつなぐ）は、本と現実を橋渡しし、言葉を"使える知識"にする強力な問いです。

月齢で変える

  • 〜18ヶ月：問いは「これ、なあに？」中心。子はまだ言葉で返せなくても、指さし・声・視線が"答え"。それを受け止めて広げる。丈夫な厚紙の本を、ページを飛ばしても好きに。
  • 18〜30ヶ月：Wh-質問と穴埋めが効き始める。同じ本の反復を歓迎する——覚えた本ほど子は語り手になれる。
  • 30〜36ヶ月：Open-ended と Distancing を増やす。「なんでだと思う？」に付き合い、脱線を楽しむ。
👨 父ができること 棒読みでも、対話ならば効く

「感情を込めて上手に読む」必要はありません。対話的読み聞かせで効くのは朗読の巧拙ではなく、問いかけと受け止めの往復です。父の低い声・違う間・思わぬ脱線は、むしろ言葉の幅を広げます。忙しい日は1ページだけ、問いかけを1つ入れるだけでも立派な対話です。

⚠️ 注意
  • 問いを質問攻めにしない。子が楽しめなくなったら本末転倒。5ページに1〜2問でも十分です。
  • 子が「読んで」と言うなら、まず読む。対話は子の乗り気があってこそ。義務にすると本嫌いを生みます。
  • 答えを「違う」と否定しない。受け止めてから、さりげなく正しい言い方を広げて返す。
