この資料の歩き方

誰のための資料か、どう読むか、そして「やってはいけないこと」。最初に読んでください。

この資料は誰のためのものか

0〜3歳の子を持つ父親のための、能力開発リファレンスです。前提を明確にします。

  • 妻が保育士で、授乳・寝かしつけ・生活リズム・衛生・安全といった基本的な育児は十分に回っている。
  • だからこの資料は基本育児を扱いません。その土台の上に、「潜在能力を引き上げる上乗せ（enrichment）」だけを、父親の視点で体系化します。
📌 要点

この資料の一貫した立場は「煽らない・急がせない・比べない」です。子どもを賢くするための働きかけが、親子関係や子どもの「やりたい」という気持ちを損なうなら本末転倒。すべては楽しい親子のやりとりとして成立することが条件です。

3つの入口

同じ情報に、3つの角度からたどり着けます。

  1. 能力から → 発達ドメイン。言語・運動・数量・実行機能など「柱」ごとに深掘り。
  2. 月齢から → 月齢ロードマップ。「今うちの子は◯ヶ月」で、その時期に効くことを引く。
  3. 今日やることから → 実践図鑑。5分でできる活動カードを、月齢・ドメインで絞り込む。

はじめての方は、まず 大前提：土台7原則 と 土台の科学 を読むと、以降のすべてが「なぜ効くか」でつながります。

エビデンスの読み方

各コンテンツにはエビデンス等級が付いています。「どれくらい信じてよいか」の目安です。

等級意味
A強い根拠（メタ分析・RCTなど一貫した強い証拠）
B中程度（一貫した観察研究・複数の支持）
C限定的（理論・専門家の合意・小規模研究）
D弱い／要注意（人気だが根拠は薄い、または誇張）

D等級は「やめておけ」ではなく「過信するな」の意味です。神話・商品化された言説は 神話と落とし穴 でまとめて是正します。

やってはいけないこと（先に釘を刺す）

⚠️ 注意
  • 詰め込み・フラッシュカード的な早期教育。効果の根拠は乏しく、関係性を損なうリスクの方が大きい。
  • 他の子との比較。発達の個人差は極めて大きく、比較は親の不安を増やすだけ。
  • 成果（できた／できない）で一喜一憂すること。育てるのは能力そのものではなく、能力が育つ「土壌」です。
  • スクリーンで代替すること（特に2歳未満）。詳細は環境デザインで。
