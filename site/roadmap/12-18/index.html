12-18ヶ月

B 中程度 粗大運動・スポーツ

歩行の獲得

独歩は12〜15ヶ月が多いが9〜18ヶ月と幅広い

芽生えるもの: つたい歩き→独歩 / しゃがむ・立つ / 押す玩具で歩く

👨 高レバレッジ活動
  • 安全に歩き回れる空間
  • 登る・降りるの機会（クッション山）

ラフ＆タンブルや"抱えて飛行機"でバランス・体幹を遊びに。

⚠️ 受診の目安（赤旗）
  • 18ヶ月で全く歩かない
  • つま先立ちが常態化
関連ラフ＆タンブル遊び粗大運動・スポーツ走る・跳ぶ・投げる
B 中程度 言語・コミュニケーション

初語〜語彙の入り口

初語は約12ヶ月、幅広い

芽生えるもの: 意味のある初語 / 指さしで要求・共有 / 簡単な指示の理解

👨 高レバレッジ活動
  • 対話的読み聞かせ
  • 子の一語を"拡張"して返す

父の語彙・話題を持ち込み、言葉の幅を広げる。

⚠️ 受診の目安（赤旗）
  • 指さしが出ない
  • 18ヶ月で意味のある語が全くない
関連対話的読み聞かせ言語・コミュニケーションことばの爆発と二語文
B 中程度 実行機能・自己制御

試行錯誤と簡単なルール

—

芽生えるもの: やり方を変えて試す（形合わせ等） / 「ちょうだい/どうぞ」の往復 / 簡単な禁止の理解（守れるとは限らない）

👨 高レバレッジ活動
  • 形合わせ・型はめパズル
  • 「どうぞ/ちょうだい」の交換あそび

すぐ答えを見せず、試行錯誤を3回待ってから最小限のヒント。

関連実行機能・自己制御おつかいミッション（もってきて遊び）「待てる力」は遊びで育つ
B 中程度 微細運動・手の巧緻性

なぐり書き・積む・スプーン

積み木2〜4個は12〜18ヶ月ごろ

芽生えるもの: クレヨンでなぐり書き / 積み木を2〜4個積む / スプーンへの挑戦（こぼしながら）

👨 高レバレッジ活動
  • 大きな紙と太いクレヨン
  • 積む・入れ子あそび
  • 自分で食べる機会（散らかり許容）

「上手に描けたね」より「いっぱい描いたね！」——過程を実況する係。

⚠️ 受診の目安（赤旗）
  • 道具（スプーン・クレヨン）に全く興味を示さない状態が続く
関連積む・入れ子微細運動・手の巧緻性つまむ力（ピンサーグリップ）の発達なぐり書きは書字の芽
B 中程度 好奇心・探索・遊び

道具としての遊び・運ぶ・出し入れ

—

芽生えるもの: 物を目的をもって使う（コップで飲むふりの芽） / 運ぶ・集める・出し入れの反復 / 同じ遊びの繰り返しを好む

👨 高レバレッジ活動
  • 出し入れできる容器・袋・箱
  • 「運ぶ仕事」を頼む（洗濯物1枚など）

反復に飽きず付き合う。「またやるの？」ではなく反復こそ学習と心得る。

関連入れる・出す遊び好奇心・探索・遊びオープンエンドな遊び
B 中程度 社会情動・共感

感情の共有と、かんしゃくの始まり

—

芽生えるもの: できた時に養育者を見て喜びを共有 / 思い通りにならない時のかんしゃく / 「いや」の意思表示

👨 高レバレッジ活動
  • 喜びの共有に全力で応じる
  • 感情のことば化（「悔しかったね」）

かんしゃくに怒りで返さない。まず気持ちを言葉に、それから切り替えの手伝い。

⚠️ 受診の目安（赤旗）
  • 感情の共有（見て・見せて）がまったくない
関連気持ちの実況（感情のことば化）社会情動・共感人見知り・後追い・分離不安感情のラベリング
C 限定的 数・量・空間認知

大小・形の実地実験

—

芽生えるもの: 大きい物に小さい物を入れる方向性の理解 / 簡単な型はめ / 「もういっこ」の要求

👨 高レバレッジ活動
  • 型はめパズル・入れ子
  • 「もういっこ？ はい、どうぞ」で数の言葉を

「どっちが大きい？」と2択で聞いて選ばせる。正誤は問わず、比べる行為を面白がる。

関連積む・入れ子数・量・空間認知数量感覚は「数えること」より「比べること」から空間認知を育てる
B 中程度 音楽・リズム・聴覚

拍とダンスの芽

—

芽生えるもの: 音楽で自発的に踊る / 楽器（マラカス等）を鳴らして楽しむ / 好きな曲の要求

👨 高レバレッジ活動
  • ダンスタイムを日課に
  • 手づくりマラカスで合奏

「パパの曲」を1曲決めて毎回同じダンスを。定番化が参加を生む。

関連手づくりマラカス（音の実験）音楽・リズム・聴覚リズムは体で育つ
B 中程度 視覚・感覚統合

全身で感じる屋外

—

芽生えるもの: 歩行による探索圏の拡大 / 砂・水・葉など自然素材への没頭 / 天候の体感（風・雨・寒暖）

👨 高レバレッジ活動
  • 毎日の外遊び
  • はだし・水たまり・砂場の解禁

汚れる遊びの引率は父の職務。着替えを持てば、雨の日も教材になる。

関連はだしの探検（足裏センサー）外あそびと自然の科学感覚の好き嫌い感触遊び（メッシー・プレイ）— 「汚れる」ことが学びになる
B 中程度 読み聞かせ・リテラシー

指さし読みと単語の収穫

—

芽生えるもの: 絵本の絵を指さして名前を求める / 知っている物の絵に反応 / 本を持ってくる

👨 高レバレッジ活動
  • 指さしに全部応じて名づける
  • 「〇〇はどこ？」の探し読み

本を持ってきたら原則断らない。「持ってくれば読んでもらえる」が読書習慣の種。

関連指さし応答読み聞かせ・リテラシー対話的読み聞かせの実際絵本の選び方と、続く読書習慣のつくり方
