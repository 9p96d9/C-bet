0-3ヶ月

B 中程度 粗大運動・スポーツ

首すわりへ向かう

首すわりは多くが3〜4ヶ月

芽生えるもの: うつ伏せで頭を持ち上げる / 手足を活発に動かす / 追視（目で追う）

👨 高レバレッジ活動
  • うつ伏せ遊び（tummy time）を少しずつ
  • 目の高さで声かけ・追視を促す

胸の上のうつ伏せで、父の顔を"的"にして頭上げを促す。

⚠️ 受診の目安（赤旗）
  • 4ヶ月で全く頭を上げようとしない
  • 手足の動きに明確な左右差
B 中程度 言語・コミュニケーション

声とやりとりの芽

社会的微笑は約2ヶ月

芽生えるもの: クーイング（母音的な発声） / 人の声への注意 / 社会的微笑

👨 高レバレッジ活動
  • 実況中継トーク（サーブ＆リターン）
  • 子の発声に間を置いて返す

低い声・歌うような抑揚（parentese）で語りかける。

⚠️ 受診の目安（赤旗）
  • 大きな音に全く反応しない
  • 2ヶ月過ぎても目が合わない/微笑まない
A 強い根拠 社会情動・共感

愛着の土台づくり

—

芽生えるもの: 泣きで欲求を伝える / 抱っこで落ち着く / アイコンタクト

👨 高レバレッジ活動
  • 泣きに一貫して応じる
  • 肌の触れ合い・抱っこ
  • 予測可能な関わりの反復

沐浴・寝かしつけなど"父の担当場面"を一つ持ち、一貫して関わる。

⚠️ 受診の目安（赤旗）
  • あやしても極端に反応が乏しい
B 中程度 視覚・感覚統合

見つめる・追う・音に向く

追視は1〜3ヶ月で滑らかに

芽生えるもの: 顔をじっと見る（20〜30cmが見やすい） / 動く物を目で追う / 音の方へ顔を向ける

👨 高レバレッジ活動
  • 顔を近づけてゆっくり動く「追視あそび」
  • コントラストの強い絵・模様を見せる

抱っこの位置＝ちょうど見える距離。父の顔そのものが最初の教材。

⚠️ 受診の目安（赤旗）
  • 光や音に全く反応しない
  • 目が合う気配がない（3ヶ月ごろ）
B 中程度 音楽・リズム・聴覚

声とリズムを浴びる

—

芽生えるもの: 養育者の声を聞き分ける / 抑揚のある声への注意 / 揺れ・リズムで落ち着く

👨 高レバレッジ活動
  • 子守唄・鼻歌を毎日（上手さ不要）
  • 抱っこでゆっくり揺れながら歌う

低い声は子宮内でも届いていた音域。父の歌・ハミングは特別な安心材料。
