0-3ヶ月

B 中程度 粗大運動・スポーツ

首すわりへ向かう

首すわりは多くが3〜4ヶ月

芽生えるもの: うつ伏せで頭を持ち上げる / 手足を活発に動かす / 追視（目で追う）

👨 高レバレッジ活動
  • うつ伏せ遊び（tummy time）を少しずつ
  • 目の高さで声かけ・追視を促す

胸の上のうつ伏せで、父の顔を"的"にして頭上げを促す。

⚠️ 受診の目安（赤旗）
  • 4ヶ月で全く頭を上げようとしない
  • 手足の動きに明確な左右差
B 中程度 言語・コミュニケーション

声とやりとりの芽

社会的微笑は約2ヶ月

芽生えるもの: クーイング（母音的な発声） / 人の声への注意 / 社会的微笑

👨 高レバレッジ活動
  • 実況中継トーク（サーブ＆リターン）
  • 子の発声に間を置いて返す

低い声・歌うような抑揚（parentese）で語りかける。

⚠️ 受診の目安（赤旗）
  • 大きな音に全く反応しない
  • 2ヶ月過ぎても目が合わない/微笑まない
A 強い根拠 社会情動・共感

愛着の土台づくり

—

芽生えるもの: 泣きで欲求を伝える / 抱っこで落ち着く / アイコンタクト

👨 高レバレッジ活動
  • 泣きに一貫して応じる
  • 肌の触れ合い・抱っこ
  • 予測可能な関わりの反復

沐浴・寝かしつけなど"父の担当場面"を一つ持ち、一貫して関わる。

⚠️ 受診の目安（赤旗）
  • あやしても極端に反応が乏しい
B 中程度 視覚・感覚統合

見つめる・追う・音に向く

追視は1〜3ヶ月で滑らかに

芽生えるもの: 顔をじっと見る（20〜30cmが見やすい） / 動く物を目で追う / 音の方へ顔を向ける

👨 高レバレッジ活動
  • 顔を近づけてゆっくり動く「追視あそび」
  • コントラストの強い絵・模様を見せる

抱っこの位置＝ちょうど見える距離。父の顔そのものが最初の教材。

⚠️ 受診の目安（赤旗）
  • 光や音に全く反応しない
  • 目が合う気配がない（3ヶ月ごろ）
B 中程度 音楽・リズム・聴覚

声とリズムを浴びる

—

芽生えるもの: 養育者の声を聞き分ける / 抑揚のある声への注意 / 揺れ・リズムで落ち着く

👨 高レバレッジ活動
  • 子守唄・鼻歌を毎日（上手さ不要）
  • 抱っこでゆっくり揺れながら歌う

低い声は子宮内でも届いていた音域。父の歌・ハミングは特別な安心材料。

B 中程度 微細運動・手の巧緻性

握って、ゆっくり開いて

把握反射から随意的な手へ移行中

芽生えるもの: 握る（反射から） / 手をじっと見つめる（ハンドリガード） / 手が口へ

👨 高レバレッジ活動
  • 指を握らせて話しかける
  • 軽い布・ガラガラを手に触れさせる

父の太い指は握りやすい鉄棒。握られたら「ぎゅっ、上手」と声を返す。

C 限定的 数・量・空間認知

量と空間の直感の芽

—

芽生えるもの: 動くものの軌跡を追う / 「多い/少ない」の大まかな区別（近似数感覚）は生得的に備わる

👨 高レバレッジ活動
  • ゆっくり動かして追視させる
  • この時期に特別なことは不要——抱っこで移動する経験自体が空間の入力

抱っこ・ベビーカーでの移動が最初の空間学習。焦って何かをする時期ではない。

B 中程度 実行機能・自己制御

「落ち着く」を体で学ぶ

—

芽生えるもの: なだめられて落ち着く経験 / 睡眠と覚醒のリズムの芽

👨 高レバレッジ活動
  • 泣きに素早く応じてなだめる（自己調整の外部足場）
  • 予測可能な日課

実行機能の最初の形は「落ち着けること」。父の腕の中で落ち着く経験が、後の自己制御の原型になる。

B 中程度 好奇心・探索・遊び

顔が最初のおもちゃ

—

芽生えるもの: 人の顔をじっと見る / 声・表情への反応 / やりとりの快の芽

👨 高レバレッジ活動
  • 顔を近づけて表情で遊ぶ
  • 声のまね返し

この時期の遊び道具は父の顔と声で十分。玩具はまだ脇役。

B 中程度 読み聞かせ・リテラシー

声の心地よさから始まる

—

芽生えるもの: 読み手の声への注意 / 抑揚・リズムを好む

👨 高レバレッジ活動
  • 膝で短い絵本を（内容よりも声と密着）
  • 声色を変えて読む

「本＝父の声と温もり」という最初の連合を作る時期。1日1分でも意味がある。
