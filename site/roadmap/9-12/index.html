9-12ヶ月

B 中程度 粗大運動・スポーツ

はいはい・つかまり立ち・伝い歩き

つかまり立ちは8〜11ヶ月ごろ（幅大）

芽生えるもの: はいはいの加速 / つかまり立ち / 伝い歩き

👨 高レバレッジ活動
  • はいはいで追いかけっこ
  • つかまれる家具の安全な配置
  • 階段や坂の探索（見守りつつ）

床に寝そべって同じ目線ではいはい競争。父が"動く障害物"になる。

⚠️ 受診の目安（赤旗）
  • 12ヶ月で支えても立とうとしない
  • 移動の意欲が極端に乏しい
A 強い根拠 社会情動・共感

社会的参照 — 顔色で世界を測る

社会的参照は9〜12ヶ月ごろ明確に

芽生えるもの: 新しい物・人の前で養育者の表情を確認する / 「だめ」の声のトーンを理解し始める / バイバイ・ぱちぱちなど社会的しぐさ

👨 高レバレッジ活動
  • 挑戦場面で穏やかな笑顔を返す（安心のGOサイン）
  • 社会的しぐさのやりとり

父の落ち着いた表情が「やってみていい」の合図になる。過剰に驚かない・慌てない。

⚠️ 受診の目安（赤旗）
  • 視線のやりとり・表情の参照がまったくない
C 限定的 数・量・空間認知

入れる・出す・はめる

—

芽生えるもの: 容器への出し入れの反復 / 大小の関係の実験（入る/入らない） / 積もうとする

👨 高レバレッジ活動
  • 入れ子カップ・箱と小物
  • 「入った！」「大きいね」の声かけ

「入らないねえ、どうする？」と実況して試行錯誤を見守る。答えは先に言わない。

B 中程度 音楽・リズム・聴覚

音楽で体が動く

—

芽生えるもの: 音楽に合わせて体を揺らす / 手遊び歌の動きをまねしようとする / 好きな歌で機嫌が変わる

👨 高レバレッジ活動
  • 手遊び歌のレパートリーを2〜3曲
  • 「うたの続き待ち」で発声を促す

踊る父ほど強い教材はない。恥は家の外に置いてくる。

B 中程度 視覚・感覚統合

感触の好みと実験

—

芽生えるもの: 素材による触り方の変化 / 食材の感触遊び（ぐちゃぐちゃ） / 冷たい/温かいへの反応

👨 高レバレッジ活動
  • 安全な素材の感触遊び
  • 手づかみ食べの許容（散らかりは学習コスト）

「汚れるからダメ」を言わない係。片付けごと引き受けて、感触の実験を保証する。

⚠️ 受診の目安（赤旗）
  • 特定の感触への極端な拒否が広範囲に及び生活に支障
B 中程度 好奇心・探索・遊び

やりとり遊びの成立

—

芽生えるもの: 「どうぞ/ちょうだい」の往復 / まねっこ遊び / 大人を遊びに誘う

👨 高レバレッジ活動
  • 物の受け渡し遊び
  • 子の動きをまね返す

子から遊びに誘われたら最優先で応じる。「誘えば来る」という確信が社会性の元手。

⚠️ 受診の目安（赤旗）
  • やりとり遊び（どうぞ・ばあ等）への関心が全く見られない
B 中程度 読み聞かせ・リテラシー

お気に入りの1冊の誕生

—

芽生えるもの: 特定の本を繰り返し要求 / 絵の指さし / 擬音への笑い

👨 高レバレッジ活動
  • 同じ本の反復に付き合う
  • 擬音を大げさに読む

100回目の「もう一回」にも初回のように付き合う——反復は語彙の定着作業。

B 中程度 微細運動・手の巧緻性

ピンサーグリップ

親指と人差し指でつまむのは9〜12ヶ月

芽生えるもの: 小さな物を指先でつまむ / 両手で持ち替える / 容器に入れる/出す

👨 高レバレッジ活動
  • 入れる・出す遊び
  • つまむ機会を作る（安全サイズで）

大きめのボルトやカラビナなど父の道具箱が題材（誤飲サイズ注意）。

⚠️ 受診の目安（赤旗）
  • 物に手を伸ばさない
  • 手を使おうとしない
B 中程度 言語・コミュニケーション

指さしと初語の入り口

指さし要求は9〜14ヶ月、初語は約12ヶ月

芽生えるもの: 指さしで要求・共有 / 簡単な言葉の理解（ちょうだい等） / 喃語が言葉らしく

👨 高レバレッジ活動
  • 指さし応答
  • ことばの拡張

子が指さすたびに立ち止まり名づける余裕を持つ。

⚠️ 受診の目安（赤旗）
  • 指さしが出ない
  • 名前や声への反応が乏しい
C 限定的 実行機能・自己制御

意図と手段（因果の理解）

—

芽生えるもの: 布を引いて物を取る等の手段-目的 / 隠した物を探す / 簡単な模倣

👨 高レバレッジ活動
  • かくれんぼ（物さがし）
  • 模倣を促す遊び

「どうやったら取れる？」と少しだけ難しい状況を作り足場をかける。
