6-9ヶ月

B 中程度 粗大運動・スポーツ

お座り〜ずりばいへ

支えなし座位は6〜9ヶ月、はいはいは個人差大

芽生えるもの: 支えなしで座る / ずりばい・はいはい / 物への手の伸ばしが正確に

👨 高レバレッジ活動
  • 自由に動ける安全な床の時間
  • 少し先に玩具を置いて移動を誘う

力強い持ち上げ・低い障害物越えなど、体を大きく使う遊びで前庭感覚を刺激（安全に）。

⚠️ 受診の目安（赤旗）
  • 9ヶ月で支えても座れない
  • 体の片側だけ使う傾向が続く
B 中程度 言語・コミュニケーション

喃語と共同注意

規準喃語（ばばば等）は約6〜9ヶ月

芽生えるもの: 子音を含む喃語（ばばば/ままま） / 名前に振り向く / 共同注意の芽（大人の視線を追う）

👨 高レバレッジ活動
  • 喃語に会話のように返す
  • 子が見ているものを名づける
  • 絵本の指さし

散歩で見えるものを名づける"名づけ探検"で語彙のシャワーを。

⚠️ 受診の目安（赤旗）
  • 9ヶ月で喃語が出ない
  • 声や名前への反応が乏しい
B 中程度 実行機能・自己制御

対象の永続性

約8ヶ月前後で芽生え

芽生えるもの: 隠れた物を探す / いないいないばあを楽しむ / 短い予測（次に何が起こるか）

👨 高レバレッジ活動
  • いないいないばあ
  • 布の下に隠した玩具を探させる

大きな表情と"ため"で予測と驚きの往復を演出。

B 中程度 微細運動・手の巧緻性

持ち替え・打ち合わせ

手から手への持ち替えは6〜8ヶ月

芽生えるもの: 手から手へ持ち替える / 両手の物を打ち合わせる / 熊手のように掻き寄せる

👨 高レバレッジ活動
  • 両手に一つずつ持たせる
  • 叩くと音が出る物で因果を体験

トントン打ち合わせを一緒に。音のやりとりはリズムあそびの入り口。

⚠️ 受診の目安（赤旗）
  • 片手しか使わない状態が続く（明確な左右差）
A 強い根拠 社会情動・共感

人見知りと安全基地

人見知り・分離不安は6〜9ヶ月ごろから

芽生えるもの: 特定の人への愛着が明確に / 知らない人への警戒（人見知り） / 养育者の表情をうかがう（社会的参照の芽）

👨 高レバレッジ活動
  • 不安な場面でしっかり受け止める
  • いないいないばあ（消えても戻る、の練習）

人見知りで父が拒まれても正常な発達のサイン。腐らず淡々と関わり続けることが効く。

⚠️ 受診の目安（赤旗）
  • 特定の人への愛着行動がまったく見られない
B 中程度 視覚・感覚統合

触って落として確かめる

—

芽生えるもの: 物を振る・叩く・落とすで性質を調べる / 食感・温度の違いへの反応 / 落ちた物を目で追う

👨 高レバレッジ活動
  • 「落とす→拾って返す」に付き合う（実験に見えるのは学習）
  • 素材・音の違う物を用意

何度落とされても拾って返す根気担当。「落ちたね、ゴトン！」と実況を添える。

C 限定的 数・量・空間認知

「ある/ない」と容器の発見

—

芽生えるもの: 隠れた物を探し始める（対象の永続性の芽） / 容器の中と外への興味

👨 高レバレッジ活動
  • 布で隠して見つける遊び
  • カップ・箱への出し入れ

「ないない…あった！」の演出係。消える→現れるの驚きが空間と記憶を育てる。

B 中程度 音楽・リズム・聴覚

叩けば鳴る — 音の因果

—

芽生えるもの: 物を叩いて音を出す / リズムに体が揺れる / 好きな歌への反応

👨 高レバレッジ活動
  • 叩くと鳴る物を用意（鍋・太鼓）
  • 同じ歌を毎日（レパートリー化）

一緒に叩いて「音のかけあい」に。うるさい時間を数分だけ許容する度量。

B 中程度 好奇心・探索・遊び

探索遊びの本格化

—

芽生えるもの: 何でも触る・振る・落とす・口で確かめる / 玩具より日用品への興味

👨 高レバレッジ活動
  • 安全な日用品の「宝箱」（木のスプーン・布・容器）
  • 床の探索圏を広げる

「ダメ」を減らすのは環境設計で。触ってよい物だけの空間を作れば、探索を止めずに済む。

B 中程度 読み聞かせ・リテラシー

絵と指さしの入り口

—

芽生えるもの: 絵への注視が長くなる / ページをめくろうとする / 読み手の指さしを目で追う

👨 高レバレッジ活動
  • 絵を指さして名づけながら読む
  • 子のペースでめくらせる（順番どおりでなくてよい）

「読み終える」ことを目標にしない。1ページで脱線しても、それが正しい読み方。
