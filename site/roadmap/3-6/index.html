3-6ヶ月

B 中程度 言語・コミュニケーション

クーイングから喃語へ

喃語（バババ等）は4〜6ヶ月ごろから

芽生えるもの: 「あーうー」（クーイング） / 声のやりとりを楽しむ / 笑い声・声の実験

👨 高レバレッジ活動
  • 声が出たらまねして返す（音のラリー）
  • parentese（抑揚豊かな語りかけ）

子の声をまねて返すだけで会話の原型になる。通勤前後の5分でも成立。

⚠️ 受診の目安（赤旗）
  • 声をほとんど出さない
  • 6ヶ月で音への反応が乏しい
関連赤ちゃん語りかけ（parentese）サーブ＆リターンparentese（対乳児発話）— 「あの声」で話すのは科学的に正しい
B 中程度 微細運動・手の巧緻性

リーチングと把握

狙って手を伸ばすのは3〜5ヶ月ごろ

芽生えるもの: 物に狙って手を伸ばす / 掴んで口へ運ぶ / 両手を体の正面で合わせる

👨 高レバレッジ活動
  • 握りやすい玩具を少し遠くに置く
  • 素材の違う物を握らせる

「あと少しで届く」距離の調整役。取れた瞬間を一緒に喜ぶ。

⚠️ 受診の目安（赤旗）
  • 5〜6ヶ月で物に手を伸ばす気配がない
関連微細運動・手の巧緻性自由に動ける床の時間
C 限定的 数・量・空間認知

距離とリーチの学習

—

芽生えるもの: 届く/届かないの学習（リーチング） / 物の大きさへの手の調整の芽

👨 高レバレッジ活動
  • 届きそうな距離に物を置く
  • 大小の握りやすい物を渡す

「あと少し」の距離設計係。届いた瞬間の達成を一緒に喜ぶ。

関連数・量・空間認知微細運動・手の巧緻性
B 中程度 実行機能・自己制御

予期と期待 — 「くる、くる…きた！」

—

芽生えるもの: 日課の流れを予期する / 「いないいない…ばあ」への期待の表情

👨 高レバレッジ活動
  • 同じ流れの遊びを繰り返し、間で期待させる
  • 生活の節目を同じ言葉で予告

「3、2、1…たかい！」のカウントで予期を作る。予測できる父は安心の源。

関連いないいないばあ実行機能・自己制御
B 中程度 音楽・リズム・聴覚

声あそびと音の実験

—

芽生えるもの: 声の高低・大小の実験（自分の声で遊ぶ） / 歌への静聴・体の反応

👨 高レバレッジ活動
  • 子の声をまねて音のラリー
  • 膝の上で拍に合わせて軽く揺れる

低い声と高い声の振り幅で笑わせる。父の声域は楽器のひとつ。

関連よびかけソング（コール＆レスポンス）音楽・リズム・聴覚聴く環境をつくる
B 中程度 好奇心・探索・遊び

繰り返しがおもしろい

—

芽生えるもの: 同じ遊びの反復を喜ぶ / 揺れ・くすぐりなど体の遊びへの笑い

👨 高レバレッジ活動
  • 「もう一回」の合図（体の動き・声）を読み取って応じる
  • 短い体あそびのレパートリーを2〜3個

反復に飽きないのが大人の仕事。子の「もう一回」は学習中のサイン。

⚠️ 受診の目安（赤旗）
  • あやしても笑いや反応がほとんどない
関連好奇心・探索・遊び
B 中程度 読み聞かせ・リテラシー

本はまず「触るもの」

—

芽生えるもの: 本に手を伸ばす・叩く・かじる / 鮮やかな絵への注視

👨 高レバレッジ活動
  • 布絵本・ボードブックを玩具として自由に
  • 短く抑揚たっぷりに読む（完読は目標にしない）

かじられても「本に興味を持った」と喜ぶ。この時期の正しい読書は五感で味わうこと。

関連絵本の選び方と蔵書づくり読み聞かせ・リテラシー
B 中程度 粗大運動・スポーツ

寝返り〜支え座り

寝返りは4〜6ヶ月ごろ

芽生えるもの: 寝返り / 支えれば座る / 足で床を蹴る

👨 高レバレッジ活動
  • 自由に動ける床時間
  • うつ伏せ遊びの継続

手の届く所に玩具を置き、寝返り・リーチを引き出す。

⚠️ 受診の目安（赤旗）
  • 首すわりが見られない
  • 極端に体が硬い/柔らかい
関連自由に動ける床の時間粗大運動・スポーツうつ伏せ遊び（tummy time）の科学と実践
B 中程度 視覚・感覚統合

手と口で世界を調べる

—

芽生えるもの: 物に手を伸ばす / 口に持っていって確かめる / 色・動きへの興味

👨 高レバレッジ活動
  • 安全で多様な感触の物を渡す
  • 多感覚で名づける

散歩で光・風・音の実況。多感覚シャワーを浴びせる。

⚠️ 受診の目安（赤旗）
  • 音や光に全く反応しない
  • 目で追わない
関連視覚・感覚統合お散歩・名づけ探検感覚の好き嫌い
B 中程度 社会情動・共感

笑いと情動の同調

声を出して笑うのは3〜4ヶ月ごろ

芽生えるもの: 声を出して笑う / 養育者との情動のやりとり / 人を見分ける

👨 高レバレッジ活動
  • 表情豊かに応じる
  • いないいないばあ

大きな表情と声で笑いを引き出す遊びは父が得意。

⚠️ 受診の目安（赤旗）
  • あやしても笑わない/反応が極端に乏しい
関連社会情動・共感いないいないばあ
