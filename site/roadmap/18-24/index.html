18-24ヶ月

B 中程度 微細運動・手の巧緻性

積み上げ・めくる・型はめ

積み木4〜6個・ページめくりは18〜24ヶ月ごろ

芽生えるもの: 積み木を高く積む / 絵本を1枚ずつめくる / 型はめ・大きなビーズ

👨 高レバレッジ活動
  • 注ぐ・移す（お水の仕事）
  • 絵本のページめくり係を任せる

崩れた時の「もう一回！」に付き合う。失敗→再挑戦の回路を育てる。

関連注ぐ・移す（お水の仕事）微細運動・手の巧緻性なぐり書きは書字の芽スプーン・コップ・はさみ
B 中程度 社会情動・共感

自我の芽生えと「じぶんで！」

イヤイヤの入り口は18ヶ月ごろから

芽生えるもの: 「じぶんで！」の主張 / 所有の主張（「〇〇ちゃんの！」） / 鏡の自分がわかる（自己認識）

👨 高レバレッジ活動
  • 時間が許す限り「じぶんで」をやらせる
  • 2択で選ばせる（「赤と青、どっち？」）

朝の忙しさで奪いがちな「じぶんで」を、休日の父時間でたっぷり保証する。

関連社会情動・共感鏡あそび人見知り・後追い・分離不安かんしゃく・イヤイヤ期の対応
B 中程度 実行機能・自己制御

簡単な指示の遂行と切り替え

—

芽生えるもの: 一段階の指示を確実に遂行 / 「おしまい」からの切り替え（練習中） / 順番の概念の芽

👨 高レバレッジ活動
  • おつかいミッション（一段階→二段階へ）
  • 「待つ」遊びを短く

切り替えは予告が9割（「あと1回滑ったらおしまいね」）。急な中断を避ける。

⚠️ 受診の目安（赤旗）
  • 簡単な指示・言葉かけへの反応が一貫して乏しい
関連おつかいミッション（もってきて遊び）「待つ」遊び「待てる力」は遊びで育つ「待てる子」の育て方
C 限定的 数・量・空間認知

2つの世界 — 「いっこ」と「いっぱい」

—

芽生えるもの: 「ひとつ」の理解の芽 / 多い/少ないの比較 / 形の区別（丸・四角）の入り口

👨 高レバレッジ活動
  • 「ひとつどうぞ」の実践
  • おやつ・積み木で多い少ないを体感

数唱を教え込むより「ひとつ取って」が通じる喜びを。数は生活の道具として。

関連生活の中で数える数・量・空間認知数量感覚は「数えること」より「比べること」から空間認知を育てる
B 中程度 音楽・リズム・聴覚

歌の一部を歌う

—

芽生えるもの: 知っている歌の語尾・サビを歌う / リズムの模倣（トントン→トントン） / 強弱の面白さ

👨 高レバレッジ活動
  • うたの続き待ち
  • リズムのまねっこ・おおきい音ちいさい音

わざと歌詞を間違えて「ちがう！」と直させる遊びは、この時期から効く。

関連おおきい音・ちいさい音音楽・リズム・聴覚リズムは体で育つうたと言葉
B 中程度 視覚・感覚統合

感覚のことば化が始まる

—

芽生えるもの: 「つめたい」「いたい」など感覚語の理解 / 感触の好み・苦手の主張 / 五感の遊びへの没頭時間の延び

👨 高レバレッジ活動
  • 感覚語を添える習慣（ざらざら・ふわふわ）
  • 感触カード・粘土・水遊び

「どんな感じ？」と問い、子の言葉を待つ。感覚を言葉にできる子は自分の状態も語れるようになる。

関連さわれる絵本・感触カード視覚・感覚統合感覚の好き嫌い感触遊び（メッシー・プレイ）— 「汚れる」ことが学びになる
B 中程度 読み聞かせ・リテラシー

物語の入り口 — 筋を追い始める

—

芽生えるもの: 短い筋のある絵本を通しで聞ける / セリフの唱和（「うんとこしょ」） / 本の中の出来事への感情反応

👨 高レバレッジ活動
  • 対話的読み聞かせ（問いを混ぜる）
  • 繰り返し構造の絵本

「次はどうなる？」の一言を足すだけで、聞く読書が考える読書になる。

関連対話的読み聞かせ読み聞かせ・リテラシー対話的読み聞かせの実際絵本の選び方と、続く読書習慣のつくり方
B 中程度 言語・コミュニケーション

語彙爆発と二語文

語彙爆発〜二語文は18〜24ヶ月ごろ

芽生えるもの: 語彙が急増 / 二語文（「わんわん いた」） / 簡単な指示に従う

👨 高レバレッジ活動
  • 対話的読み聞かせ
  • ことばの拡張
  • 絵本でお話づくり

父の語彙・話題を持ち込み、言葉の幅を広げる。

⚠️ 受診の目安（赤旗）
  • 24ヶ月で二語文の兆しがなく語彙が極端に少ない
  • 理解も乏しい
関連ことばの拡張（足して返す）言語・コミュニケーションことばの爆発と二語文
B 中程度 粗大運動・スポーツ

走る・登る・蹴る

走行・階段は個人差大

芽生えるもの: 走る / 低い段を登る / ボールを蹴る/投げる（粗い形）

👨 高レバレッジ活動
  • クッション障害物コース
  • ボール転がし・受け渡し

公園の低い遊具や外遊びで多様な動きを幅広く。

⚠️ 受診の目安（赤旗）
  • 歩行が安定しない
  • 動きの左右差が続く
関連クッション障害物コース粗大運動・スポーツ走る・跳ぶ・投げる危ないあそび（リスクのある遊び）— 「適度な危なさ」は学びになる
B 中程度 好奇心・探索・遊び

ふり遊びの芽生え

見立て遊びは18ヶ月ごろから

芽生えるもの: 物を別の物に見立てる / 人形の世話のまね / 大人の模倣遊び

👨 高レバレッジ活動
  • ごっこ遊び（見立て）
  • オープンエンドな玩具

父も本気で役に入る。恥ずかしがらず一緒になりきる。

⚠️ 受診の目安（赤旗）
  • 模倣やふりが全く見られない
関連ごっこ遊び（見立て）好奇心・探索・遊びオープンエンドな遊びふり遊びの育ち方
