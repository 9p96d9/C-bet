24-30ヶ月

B 中程度 粗大運動・スポーツ

両足ジャンプ・ボールを蹴る

両足ジャンプは24〜30ヶ月ごろ

芽生えるもの: その場で両足ジャンプ / 狙ってボールを蹴る / 階段を手すりで昇降

👨 高レバレッジ活動
  • 低い段からのジャンプ遊び（手をつないで）
  • まてまて（追いかけっこ）

「せーの、ジャンプ！」の着地を支える係。成功体験の量産が身体の自信になる。

⚠️ 受診の目安（赤旗）
  • 走れない・極端な転びやすさが続く
関連まてまて〜（追いかけっこ）粗大運動・スポーツ走る・跳ぶ・投げる危ないあそび（リスクのある遊び）— 「適度な危なさ」は学びになる
B 中程度 言語・コミュニケーション

文が伸びる・質問が始まる

—

芽生えるもの: 三語文へ / 「これなに？」の質問 / 代名詞・助詞の芽

👨 高レバレッジ活動
  • 「これなに？」に答えて一歩広げる
  • 写真でおしゃべり（思い出トーク）

同じ質問の繰り返しにも新しい一言を足して返す。質問期は語彙獲得の黄金期。

⚠️ 受診の目安（赤旗）
  • 二語文がまだ見られない場合は相談を検討
関連写真でおしゃべり（思い出トーク）ことばの拡張（足して返す）ことばの爆発と二語文
B 中程度 好奇心・探索・遊び

ごっこの筋書きと並行遊び

—

芽生えるもの: 2〜3手順のごっこ（注ぐ→飲む→「おいしい」） / 他児のそばで遊ぶ（並行遊び） / お気に入りの筋の反復

👨 高レバレッジ活動
  • ごっこに役として参加
  • キッチンお手伝い（本物への参加）

客役・患者役など「受けの演技」で子の筋書きを引き出す。

⚠️ 受診の目安（赤旗）
  • ふり遊びがまったく出ない
関連ごっこ遊び（見立て）キッチンお手伝い（混ぜる・ちぎる・運ぶ）オープンエンドな遊びふり遊びの育ち方
B 中程度 微細運動・手の巧緻性

ぐるぐる描きと道具の上達

—

芽生えるもの: ぐるぐる円のなぐり書き / スプーン・フォークの安定 / ねじる動作（ふた開け）の芽

👨 高レバレッジ活動
  • 毎日描ける環境（紙とクレヨンを出しっぱなしに）
  • ふた付き容器・ねじのおもちゃ

ペットボトルのふた開け係を任命。「ねじる」は生活の中で一番練習できる。

関連おふろ・窓のおえかき（消せるお絵かき）微細運動・手の巧緻性なぐり書きは書字の芽スプーン・コップ・はさみ
B 中程度 音楽・リズム・聴覚

歌って踊れる — 表現の始まり

—

芽生えるもの: 1曲を通して歌おうとする / 振り付きの歌の再現 / 即興の歌（自作ソング）

👨 高レバレッジ活動
  • 子の自作ソングに伴奏（手拍子）をつける
  • ダンス＆ストップで緩急

子が歌い出したら止めない・直さない。即興の歌は言語と創造の交差点。

関連ダンス＆ストップ音楽・リズム・聴覚リズムは体で育つうたと言葉
C 限定的 視覚・感覚統合

感覚を使い分ける

—

芽生えるもの: 見ないで触って当てる遊びができ始める / 音だけで物を当てる / 匂い・味の言葉の芽

👨 高レバレッジ活動
  • 袋の中身を手探りで当てる遊び
  • おとさがし（耳をすます）

「目をつぶってごらん」——1つの感覚を切って遊ぶと、他の感覚が主役になる。

関連おとさがし（耳をすます遊び）視覚・感覚統合感覚の好き嫌い感触遊び（メッシー・プレイ）— 「汚れる」ことが学びになる
B 中程度 読み聞かせ・リテラシー

「よんで」の連続と暗唱

—

芽生えるもの: お気に入りの本の暗唱（覚えて"読む"ふり） / 長めの物語を聞ける / 文字への漠然とした興味

👨 高レバレッジ活動
  • 暗唱の"読み聞かせごっこ"に観客として付き合う
  • 図書館の日で本の幅を広げる

子が「読んでくれる」ときは最高の観客になる。読む側の経験が本好きを固める。

関連図書館の日（本のえらぶ経験）読み聞かせ・リテラシー対話的読み聞かせの実際絵本の選び方と、続く読書習慣のつくり方
B 中程度 実行機能・自己制御

自己主張と、待つ力の芽

イヤイヤ期の中心は2歳前後

芽生えるもの: 強い自己主張（イヤイヤ） / 短い順番待ち / 簡単なルールのある遊び

👨 高レバレッジ活動
  • 「待つ」遊び
  • ダンス＆ストップ
  • 感情の実況

「我慢」を罰でなくゲームにする。感情を受け止めてから対処。

関連「待つ」遊び実行機能・自己制御「待てる子」の育て方「集中できる子」の育て方
C 限定的 数・量・空間認知

数え始め・大小・分類

数唱の入り口は2歳ごろ

芽生えるもの: 「いち・に・さん」の数唱 / 大小・多少の比較 / 色や形で分ける

👨 高レバレッジ活動
  • 生活の中で数える
  • 仲間分け（分類あそび）
  • 積む・入れ子

階段・おやつ・お手伝いに数と比較を混ぜる。

関連生活の中で数える数・量・空間認知数量感覚は「数えること」より「比べること」から空間認知を育てる
B 中程度 社会情動・共感

感情のことばと共感の芽

—

芽生えるもの: 感情を言葉にし始める / 他者の気持ちへの関心 / 簡単ななぐさめ

👨 高レバレッジ活動
  • 気持ちの実況（感情のことば化）
  • 絵本で気持ちを考える

父自身が感情を言葉にし、落ち着くモデルを見せる。

⚠️ 受診の目安（赤旗）
  • 視線・やりとり・関わりの乏しさが続く
関連気持ちの実況（感情のことば化）社会情動・共感かんしゃく・イヤイヤ期の対応感情のラベリング
