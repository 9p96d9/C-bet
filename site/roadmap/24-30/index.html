24-30ヶ月

B 中程度 粗大運動・スポーツ

両足ジャンプ・ボールを蹴る

両足ジャンプは24〜30ヶ月ごろ

芽生えるもの: その場で両足ジャンプ / 狙ってボールを蹴る / 階段を手すりで昇降

👨 高レバレッジ活動
  • 低い段からのジャンプ遊び（手をつないで）
  • まてまて（追いかけっこ）

「せーの、ジャンプ！」の着地を支える係。成功体験の量産が身体の自信になる。

⚠️ 受診の目安（赤旗）
  • 走れない・極端な転びやすさが続く
B 中程度 言語・コミュニケーション

文が伸びる・質問が始まる

—

芽生えるもの: 三語文へ / 「これなに？」の質問 / 代名詞・助詞の芽

👨 高レバレッジ活動
  • 「これなに？」に答えて一歩広げる
  • 写真でおしゃべり（思い出トーク）

同じ質問の繰り返しにも新しい一言を足して返す。質問期は語彙獲得の黄金期。

⚠️ 受診の目安（赤旗）
  • 二語文がまだ見られない場合は相談を検討
B 中程度 好奇心・探索・遊び

ごっこの筋書きと並行遊び

—

芽生えるもの: 2〜3手順のごっこ（注ぐ→飲む→「おいしい」） / 他児のそばで遊ぶ（並行遊び） / お気に入りの筋の反復

👨 高レバレッジ活動
  • ごっこに役として参加
  • キッチンお手伝い（本物への参加）

客役・患者役など「受けの演技」で子の筋書きを引き出す。

⚠️ 受診の目安（赤旗）
  • ふり遊びがまったく出ない
B 中程度 実行機能・自己制御

自己主張と、待つ力の芽

イヤイヤ期の中心は2歳前後

芽生えるもの: 強い自己主張（イヤイヤ） / 短い順番待ち / 簡単なルールのある遊び

👨 高レバレッジ活動
  • 「待つ」遊び
  • ダンス＆ストップ
  • 感情の実況

「我慢」を罰でなくゲームにする。感情を受け止めてから対処。

C 限定的 数・量・空間認知

数え始め・大小・分類

数唱の入り口は2歳ごろ

芽生えるもの: 「いち・に・さん」の数唱 / 大小・多少の比較 / 色や形で分ける

👨 高レバレッジ活動
  • 生活の中で数える
  • 仲間分け（分類あそび）
  • 積む・入れ子

階段・おやつ・お手伝いに数と比較を混ぜる。

B 中程度 社会情動・共感

感情のことばと共感の芽

—

芽生えるもの: 感情を言葉にし始める / 他者の気持ちへの関心 / 簡単ななぐさめ

👨 高レバレッジ活動
  • 気持ちの実況（感情のことば化）
  • 絵本で気持ちを考える

父自身が感情を言葉にし、落ち着くモデルを見せる。

⚠️ 受診の目安（赤旗）
  • 視線・やりとり・関わりの乏しさが続く
