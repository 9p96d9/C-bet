つみきタワー（高く積んで、崩す）

積み木を高く積み上げて、崩す。バランスを取りながら重ねる集中と、崩れる因果の面白さを味わう。

道具: 積み木

やり方

  1. 積み木を1個ずつ慎重に積む
  2. 「何個まで積めるかな？」と数えながら重ねる
  3. 崩れたら「がしゃーん！」と一緒に楽しむ
  4. 橋・家など形づくりにも発展させる
🧠 なぜ効くのか

積み木を安定して積む作業は、手の微細な制御とバランスの見積もり、集中の持続を要する。「崩れる」因果や、高さ・数を意識する経験は空間認知と数量感覚を育てる。崩す解放感が再挑戦の意欲を生む。

👨 父ならではの強み

「あと1個いけるかな？」と限界に挑ませ、崩れたら一緒に大笑い。崩れる楽しさを許すのが父の余裕。

バリエーション

  • 色や形の順に積む（パターン）
  • 倒さずに何個抜けるか（バランス抜き）
⚠️ 注意

高く積んだ物が頭に落ちない位置で。投げないルールを決める。
