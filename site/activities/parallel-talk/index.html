パラレルトーク（子の行動を実況）

子が今していることを、そのまま言葉にして返す。「積んでるね、赤いの乗せた」。子の関心に沿った言葉のシャワー。

道具: 不要

やり方

  1. 子が見ている・している対象に自分も注目する
  2. その行動や対象を短く言葉にする（「わんわん、みてるね」）
  3. 指示や質問攻めにせず、そのまま描写する
  4. 子の反応があれば受けて返す
🧠 なぜ効くのか

子が今注意を向けている対象に言葉を重ねる（共同注意に沿った入力）と、言葉と意味が結びつきやすい。子の関心を追う応答的な言葉かけは、語彙獲得と関連することが繰り返し観察されている（因果は限定的）。

👨 父ならではの強み

教え込もうとせず「実況アナ」に徹する。父の落ち着いた実況が、子の遊びを邪魔せず言葉を添える。

バリエーション

  • 自分の行動を実況するセルフトーク版
  • 入浴・食事など生活場面で
言語・コミュニケーション 社会情動・共感 実行機能・自己制御
