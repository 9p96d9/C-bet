手づくり写真絵本（じぶんだけの本）

家族や身近な物の写真でオリジナル絵本を作る。「自分が出てくる本」は関心が桁違いで、語りと読む意欲を引き出す。

道具: 写真（印刷） / ノート・アルバム / のり・ペン

やり方

  1. 家族・ペット・好きな物・出かけた場所の写真を集める
  2. ノートに貼り、一言そえる（「パパとこうえん」）
  3. 子と一緒にめくり、写っている人・物を名づける
  4. 繰り返し読み、子に「これだあれ？」と語らせる
🧠 なぜ効くのか

自分や身近な人が登場する本は情緒的な関与が強く、注意と発話を引き出しやすい。個人化された題材は語彙と語りの練習の場になり、「本は自分の話ができる楽しいもの」という態度を育てる。

👨 父ならではの強み

写真を選び・貼り・短い文を添える工作は父の見せ場。「パパと作った本」という愛着が読む動機になる。

バリエーション

  • 一日の出来事を写真で「今日の本」に
  • 「だれ？」「なにしてる？」と質問を足す
