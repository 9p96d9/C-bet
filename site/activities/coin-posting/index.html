ポットン落とし（すきまに入れる）

コインや札を細い口に落とし入れる。狙って入れる集中と、消えて出てくる不思議を味わう定番あそび。

道具: ふた付き容器 / 落とす物（大きめのコイン状・ペットボトルのふた等）

やり方

  1. ふたに細い口を開けた容器を用意する
  2. 大きめの物を「ポットン」と落として見せる
  3. 子に狙って入れさせる
  4. 中を開けて「あった！」と取り出す
🧠 なぜ効くのか

小さな物を細い口に狙って入れる動作は、指先の精密なコントロールと目と手の協応、向きを合わせる空間調整を育てる。入れた物が容器の中に「ある」と分かる経験は、物の永続性の理解にもつながる。

👨 父ならではの強み

牛乳パックと廃材で「ポットン落とし」を工作するのは父のDIY。口の向き・幅を変えて難度を作れる。

バリエーション

  • 貯金箱にコインを入れる
  • 色・数を数えながら入れる
⚠️ 注意

誤飲サイズの物は使わない。ペットボトルのふた等、口に入らない大きさで必ず見守って。
