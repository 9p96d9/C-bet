なくなったの なあに（記憶トレイ）

いくつかの物を見せてから1つ隠し、「何がなくなった？」と当てる。見たものを覚えておくワーキングメモリの遊び。

道具: 身近な小物2〜4個 / 布・箱

やり方

  1. 小物を2〜3個並べて名前を確認する
  2. 「よく見てね」と少し眺めさせる
  3. 布で隠して1つこっそり抜く
  4. 「なにがなくなった？」と当てさせる（数は徐々に増やす）
🧠 なぜ効くのか

並んだ物を記憶に保持し、消えた物と照合して答える課題は、ワーキングメモリと注意を使う。物の数を増やすことで難度を調整でき、成功体験を積みながら記憶の負荷を少しずつ上げられる。

👨 父ならではの強み

隠す手品のような演出が父の腕の見せどころ。「よーく見てて…」の間で注意を集める。

バリエーション

  • 位置を入れ替える版（何が動いた？）
  • 2個増やして難度アップ
⚠️ 注意

誤飲サイズの小物は使わない。
