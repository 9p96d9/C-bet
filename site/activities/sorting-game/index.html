仲間分け（分類あそび）

色・形・大きさで物を分ける。分類・比較・論理の芽と、実行機能の切り替えを育てる。

道具: 分類できる物（積み木・洗濯物・ボタン等）

やり方

  1. 分けられる物を用意（色や形が違う積み木など）
  2. 「赤はこっち、青はこっち」と基準を示す
  3. 子に分けさせ、できたら喜ぶ
  4. 慣れたら基準を変える（色→形）
🧠 なぜ効くのか

共通点で分ける経験は、分類・比較・抽象化の土台。基準を切り替える遊びは認知的柔軟性（実行機能）を刺激する。

👨 父ならではの強み

洗濯物の色分け、工具の仕分けなど"お手伝い"に混ぜると実用と学びが両立。

バリエーション

  • 大小で分ける
  • 2つの基準を組み合わせる（赤くて丸い）
⚠️ 注意

誤飲サイズの物は避ける。
