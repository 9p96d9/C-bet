お片付けゲーム（おうちに帰そう）

「ブロックさん、おうちに帰るよ」——片付けを分類ゲームに変える。分類・完遂・生活習慣を一度に。

道具: おもちゃと置き場所（箱・棚）

やり方

  1. 置き場所に「おうち」の見立てを作る（箱に絵や写真を貼ると◎）
  2. 「ブロックさんをおうちに帰そう」と誘う
  3. 「赤いのはどこかな？」と分類の声かけをする
  4. 全部帰ったら「空っぽになった！」と完了を一緒に確認する
🧠 なぜ効くのか

仲間ごとに戻す行為は分類の実践で、「最後までやり切って完了を確認する」経験は目標の保持と完遂（実行機能）を育てる。ゲーム化は強制より自発を引き出し、習慣として定着しやすい。

👨 父ならではの強み

遊びの終わりを父が「もう一つのゲーム」に変換する。叱って片付けさせるより早くて楽しい。

バリエーション

  • 「歌が終わるまでに」とタイムチャレンジ
  • 写真ラベルで文字なしでも場所がわかる棚に
実行機能・自己制御 数・量・空間認知 社会情動・共感
