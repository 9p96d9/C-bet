じぶんの絵本づくり（写真とことば）

紙を折って綴じ、子の写真や絵を貼って「◯◯ちゃんのほん」を作る。本という形式そのものへの愛着を育てる。

道具: 紙数枚 / のり / 写真か子の絵 / ホチキスか紐

やり方

  1. 紙を半分に折って重ね、簡単に綴じる（綴じは父担当）
  2. 各ページに写真や子の絵を一緒に貼る
  3. 子が言った言葉をそのまま文として書き添える（「ぶーぶ、はやい」）
  4. 完成したら表紙に名前を書き、寝る前に「作者ご本人」と一緒に読む
🧠 なぜ効くのか

自分の言葉が文字になり、ページをめくると順に現れる——本の仕組み（表紙・ページ・文字の方向）を作り手として体験できる。「読まれる喜び」は本への動機づけを強くし、読み聞かせ習慣を自走させる。

👨 父ならではの強み

印刷・工作・製本は父が段取りしやすい休日プロジェクト。できた本は本棚の「一軍」に置き、何度も読み返す。

バリエーション

  • 「きょうの公園」など1テーマ1冊で量産
  • 祖父母へのプレゼントにして「読者」を増やす
⚠️ 注意

ホチキス・はさみは父が扱い、手の届かない所へ。

読み聞かせ・リテラシー 微細運動・手の巧緻性 好奇心・探索・遊び
