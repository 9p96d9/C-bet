おおきい音・ちいさい音

太鼓や手拍子を「ありさんの音」「ぞうさんの音」で叩き分ける。強弱の制御は音楽と自己制御の交差点。

道具: 叩ける物（鍋・箱・太鼓）か手拍子だけでも

やり方

  1. 「ぞうさんの音!」で大きく叩いて見せる
  2. 「ありさんの音…」で小さくそっと叩く
  3. 交互に切り替えて、子に追従させる
  4. 慣れたら子が指揮者になって父が従う
🧠 なぜ効くのか

強弱の叩き分けは、力の出力を意図的に調整する練習（固有感覚と抑制制御）で、音のダイナミクスへの感受性も育てる。合図での切り替えはルールの保持と柔軟性を働かせる。

👨 父ならではの強み

「ぞうさん!」で豪快に、「ありさん…」で息をひそめる——振り幅の演技は父向き。

バリエーション

  • はやい/ゆっくりバージョン
  • 声の大小バージョン（ささやき声あそび）
音楽・リズム・聴覚 実行機能・自己制御 視覚・感覚統合
