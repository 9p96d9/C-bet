## 道具・素材リスト

本資料の[実践図鑑](/activities/)に登場する道具の総覧です。原則は一つ——**高価な知育玩具は要りません**（→ [玩具の選び方](/environment/02-toys/)）。

### 買わなくていい（家にある物）

| 物 | 使う活動 |
|---|---|
| 鍋・木のスプーン | リズム打ち、ままごと |
| ペットボトル＋米・豆 | 手づくりマラカス |
| 段ボール箱 | トンネル、車、お店、なんでも |
| クッション・布団 | 障害物コース |
| タオル・布 | いないいないばあ、物かくし、マント |
| プラコップ・容器 | 入れ子、注ぐ・移す、分配 |
| 洗濯物 | 仲間分け、お手伝い |
| スマホの写真 | 思い出トーク（視聴でなく対話に使う） |

### 買うなら少数精鋭（オープンエンド優先）

| 物 | 育つもの | 目安月齢 |
|---|---|---|
| 積み木（無地でシンプルな物） | 空間・微細運動・見立て | 9ヶ月〜長く |
| やわらかいボール（大小） | 協応・操作系の動き | 6ヶ月〜 |
| 太いクレヨンと大きな紙 | 微細運動・表現 | 12ヶ月〜 |
| 絵本（ボードブック中心に） | 言語・リテラシー全般 | 0ヶ月〜 |
| 割れないミラー | 自己認識・表情 | 3ヶ月〜 |
| 型はめ・入れ子カップ | 試行錯誤・空間 | 10ヶ月〜 |
| 子ども用の本物風道具（ほうき・じょうろ等） | お手伝い・自律 | 18ヶ月〜 |

### 父の"設備投資"はモノより場所と時間

- **図書館カード** — 蔵書は借りて増やす（[図書館の日](/activities/library-habit/)）
- **行ける公園のリスト** — 地形・遊具の違う公園を数カ所開拓（[週末ミニ冒険](/activities/weekend-adventure/)）
- **汚れてよい服と着替え** — 「汚れるからダメ」を減らす準備
- **床の安全なスペース** — 最強の遊具は自由に動ける床（[環境デザイン](/environment/)）

:::warning 買う前のチェック
「光る・鳴る・しゃべる」機能が多いほど、子の側の仕事が減ります。買う前に「この玩具、子どもが90%働くか？」と自問を（→ [玩具の選び方](/environment/02-toys/)）。
:::
