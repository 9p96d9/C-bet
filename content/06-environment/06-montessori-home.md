「モンテッソーリ」は教具や教室の名前として売られがちですが、家庭で価値があるのは**環境の設え方の原則**です。この章はメソッドの信奉でも宣伝でもなく、使える部分だけを借ります。

:::science 評価は正直に
モンテッソーリ教育そのものの効果研究は、質の高いものが少なく結果もまちまちです（本格的な実施校で実行機能や学業に好ましい関連を示した研究がある一方、差が出ない研究もある）。ここで紹介する家庭の設えは「メソッドの効果」としてではなく、**自律性の支援・自分でやり遂げる経験・秩序ある環境が幼児の意欲と自己制御の発達と関連する**、というより一般的な発達研究と整合するから採る——という位置づけです。
:::

## 原則は4つ

### 1. 子どもサイズ・子どもの高さ

大人の家は、子にとって「何もかも届かない家」です。**届けば、自分でできる**。

| 場所 | 設え（例） |
|---|---|
| 玄関 | 低いフックに自分の上着、靴を置く定位置 |
| 洗面 | 踏み台＋手の届くタオル |
| 食卓 | 自分で座れる椅子。コップ・食具は低い棚に |
| 部屋 | 低い本棚（表紙が見える向き）、床にマットの遊び場 |
| 服 | 低い引き出しに「今日の服」を2択で |

### 2. 少なく、見えるように

玩具箱にごちゃっと入れるより、**低い棚に数点だけ、間隔を空けて置く**。子は選べるようになり、片づけの「戻す場所」も一目で分かります。残りはしまって時々入れ替え（ローテーション → [玩具の選び方](/environment/02-toys/)）。物が少ないほど一つの遊びが深くなります。

### 3. 本物を、本気で使わせる

おままごとのフライパンより、本物の泡立て器。**日常の家事は最高の教材**です。レタスをちぎる、テーブルを拭く、洗濯物を運ぶ——「お手伝い」ではなく本当の仕事として任せると、[手の巧緻性](/domains/fine-motor/)と「自分は役に立つ」という感覚が同時に育ちます（→ [キッチンお手伝い](/activities/kitchen-helper/)・[お着替えの自立](/activities/dressing-autonomy/)）。

### 4. 秩序 — 物には決まった場所

1〜3歳の子は「いつもの場所・いつもの順番」に強い安心を感じます。物の定位置が決まっている家は、子が世界を予測できる家です。片づけは躾ではなく**ゲームとして**（→ [お片づけゲーム](/activities/cleanup-game/)）。

:::father 週末DIYでできる順に
1. **今夜できる**: 玩具を7割しまい、残りを棚に間隔を空けて並べる。本棚の一段を子の高さにして表紙を見せる。
2. **今週末**: 玄関に低いフック1本、洗面に踏み台。「自分でできた」が毎日2回増える。
3. **その先**: 床置きマットの遊びコーナー（→ [イエススペース](/environment/05-risk-balance/)）、子ども用の机と椅子。

買い足すより**下げる・減らす・空ける**が先。高価な「モンテッソーリ教具」を揃える必要はありません。
:::

:::warning 待つ時間が本体
設えを整えても、大人が先回りして手を出せば意味がありません。自分で靴を履くのは大人の5倍かかります。**急いでいない場面を選んで任せ、黙って待つ**——ここが一番難しく、一番効く部分です。「自分でやりたい」が爆発する1〜3歳の敏感な時期に、「できた」を横取りしないこと。
:::

:::keypoint
家を子ども仕様にする目的は、英才教育ではなく**「自分でできる」の回数を最大化する**こと。毎日の小さな成功体験が、意欲と[実行機能](/domains/executive-function/)の土台になります。効果を盛らず、設えの知恵だけ借りましょう。
:::
