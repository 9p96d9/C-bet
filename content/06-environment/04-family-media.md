[スクリーンタイム方針](/environment/01-screen-time/)は「子に何をどれだけ見せるか」の話でした。この章はその続き——**子が直接見ていないメディア**の話です。実は家庭のメディア環境で大きいのは、つけっぱなしのテレビと、親の手の中のスマホです。

## 背景テレビ — 誰も見ていなくても、効いている

:::science 「ながら」が遊びと会話を削る
大人向け番組がつけっぱなしの部屋では、乳幼児は数十秒ごとに遊びを中断されます。観察研究では、背景テレビがある間は**遊びの持続時間が短くなり、集中の質が下がり、親子の会話量（語数・やりとりの往復）が減る**ことが一貫して示されています。子は「見ていない」ように見えても、音と光の変化に注意を持っていかれ続けます。長時間の背景テレビへの曝露は言語発達の遅れとの関連も報告されています（多くは観察研究で、因果の強さは限定的）。
:::

対策はシンプルで、**「見る時につけて、見終わったら消す」**。BGM代わりのテレビをやめるだけで、家庭の会話量と遊びの深さの条件が変わります。音が欲しければ音楽に。

## 親のスマホ — 応答の最大の競合相手

:::science テクノフェレンス（technoference）
親がスマホに注意を向けている間、子の発信への応答は遅れ、短くなり、機械的になります。食事場面の観察では、スマホを使う親ほど子への声かけが減り、子の呼びかけを見落とすことが示されています。[サーブ＆リターン](/science/05-serve-return/)は「子の発信に素早く応じる」ことが核なので、**親の画面時間は、子の視聴時間と同じくらい言語・愛着の環境を左右します**。親のメディア使用の多さと子の行動面の問題との関連も報告されています（相関であり、因果は限定的）。
:::

ゼロにする必要はありません。**「子と遊ぶ時間は物理的に手の届かない場所に置く」**——通知が視界に入らないだけで、応答の速さは変わります。

## ビデオ通話は例外 — 使い方で「双方向」になる

:::keypoint
祖父母などとの**ビデオ通話は、録画された動画と違って双方向のやりとりが成立**し、乳児でも相手を学習できることが実験で示されています。2歳未満でも例外扱いでよいスクリーンです。親が横で「ばあばだね」「バイバイは？」と橋渡しすると、やりとりとして機能しやすくなります。
:::

## 家族メディアプラン — 「決めておく」が一番効く

その場その場で判断すると、疲れている日ほど画面が増えます。**先にルールを家族で決めて、例外を例外として扱う**のが現実的です。

| 決めること | 例 |
|---|---|
| スクリーンフリーの時間 | 食事中・寝る前1時間・遊びの時間 |
| スクリーンフリーの場所 | 寝室・食卓 |
| 背景テレビ | 見る番組だけつけ、終わったら消す |
| 親のスマホ | 遊び相手をする間は棚の上。緊急連絡は音で分かる設定に |
| 見せる時 | 内容を選び、できるだけ一緒に見て話す（→ [方針](/environment/01-screen-time/)） |
| 非常時ルール | 移動・待合室などは例外と決めておく（→ [スマホあやしの神話](/myths/#phone-to-calm)） |

:::father 父の出番
- **まず自分の使用を設計する。** 子は「スマホを見る大人」を毎日観察して育つ。帰宅後30分だけでも"圏外"になる時間を作る。
- **妻と同じルールを持つ。** 片方だけ厳しいと運用が破綻し、揉め事の種になる。プランは夫婦で合意して文字にする。
- **消した後の受け皿を持つ。** テレビを消すなら代わりの遊びを出せるように（→ [実践図鑑](/activities/)の5分カード）。「消すだけ」は続かない。
:::

:::warning
これは家庭の完璧さを競う話ではありません。疲れた日に画面に頼ることは誰にでもあります。大事なのは**既定値（デフォルト）をどちらに置くか**。デフォルトが「消えている家」なら、例外の日は例外で済みます。
:::
