微細運動の全体像は[ハブ](/domains/fine-motor/)、つまむ力の発達は[ピンサーグリップ](/domains/fine-motor/pincer-grip/)、描く行為は[なぐり書きは書字の芽](/domains/fine-motor/scribble-to-writing/)にまとめました。この記事は**道具**——スプーン・コップ・はさみといった、手と自立が交差する領域です。

## 道具が難しい理由

物を直接つかむのと、道具を介して物に働きかけるのは、脳にとって別の仕事です。

:::science 道具は「手の延長」として学ばれる
道具を使うとき、脳は道具の先端まで含めて自分の体の一部のように扱う必要があります（身体図式の拡張）。さらに、**目で見た位置・力加減・順序**を同時に制御しなければならず、つまむだけの動作よりはるかに負荷が高い。だから道具の習得は、握りの発達（→ [ピンサーグリップ](/domains/fine-motor/pincer-grip/)）が先にあり、その上に積み上がります。家庭場面で獲得時期を検証した研究は乏しく、以下の順序も目安として読んでください（等級C）。
:::

## おおまかな順序

| 月齢 | できはじめること |
|---|---|
| 9〜12ヶ月 | 手づかみ食べ、コップに口をつける（こぼす前提） |
| 12〜18ヶ月 | スプーンを握って口へ運ぼうとする（半分こぼす）、両手コップ |
| 18〜24ヶ月 | スプーンですくって運ぶ、片手コップ、小さな水差しで注ぐ |
| 24〜30ヶ月 | フォークで刺す、ふたを回す、大きなボタン、シール貼り |
| 30〜36ヶ月 | はさみで一回切り（見守り必須）、ファスナー、かんたんな箸の入り口 |

:::keypoint
どれも「教えて習得させる」ものではなく、**失敗しても大丈夫な形で機会を出し続ける**と、ある日できるようになるものです。練習させるより、日常に組み込むほうが回数が稼げます。
:::

## 道具選びで難度は下がる

うまくいかない原因の多くは、子の能力ではなく**道具が大人向け**であることです。

- **スプーン**：柄が短く太い、皿が浅め。長い柄はてこが効きすぎて口に入りません。
- **食器**：縁が立ち上がった皿・滑り止め。すくう動作が一気に成立します。
- **コップ**：小さくて重心が低いもの。中身は**少量**（こぼす量＝失敗のコストを下げる）。
- **水差し**：子の手で持てる小さなもの。注ぐ練習は水で（→ [水うつし](/activities/water-pouring/)）。
- **はさみ**：小さい・切れ味が鈍すぎないもの。切れないはさみのほうが力任せになり危険です。必ず座って、見守りのもとで。
- **服**：かぶるだけ、大きなボタン、面ファスナー（→ [じぶんで着る](/activities/dressing-autonomy/)）。

道具が届く場所にあることも同じくらい効きます（→ [自分でできる家](/environment/05-self-serve-home/)）。

## 練習になる遊び

食事の場で練習させると、空腹と時間の制約でお互い消耗します。**遊びの中で先に手を慣らす**ほうが早い。

- 乾いた豆やポンポンをスプーンで移す（→ [スプーンでうつす](/activities/spoon-transfer/)）
- トングでつまんで移す（→ [トングでつまむ](/activities/tongs-pickup/)）
- 粘土をちぎる・丸める・切る（→ [ねんど遊び](/activities/playdough-play/)）
- 料理の下ごしらえに参加する（→ [キッチンのお手伝い](/activities/kitchen-helper/)）

:::father 父の得意領域：本物を、安全な範囲で
子にとって本物の道具ほど魅力的なものはありません。おもちゃの工具より、本物のドライバーで**実際にネジが回る**経験のほうが集中も達成感も段違いです。父の側の仕事は、危険な部分だけを引き受けて、残りを本人にやらせること——「押さえるのはパパ、回すのは君」。手を出す前に、**まず3秒待つ**。この待ち時間が、そのまま巧緻性の練習量になります。
:::

## つまずきポイント

:::warning こぼす前提で設計する
「まだこぼすから」と道具を取り上げると、練習の機会が消えます。こぼれても困らない設計にするのが先です——床に新聞紙やマット、中身は少量、服は汚れていいもの。**片づけのコストを下げれば、親の側の許容量が上がります。**
:::

:::warning 手を添えすぎない・直しすぎない
後ろから手を持って動かすと、その場は成功しますが、本人は制御を学びません。困っているときは、**やり方を見せる（モデル）→少し手伝う→引く**の順で。握り方は自然に整っていくので、この時期に矯正する必要はありません（利き手も同様 → [利き手矯正の神話](/myths/#handedness-correction)）。
:::

:::keypoint
道具の習得は、教え方より**道具・量・場所**の設計でほとんど決まります。子サイズの道具を、届く場所に、こぼれても困らない状況で。あとは待つだけです。
:::
